# Mots · 辭典與單字學習

採用 Apple Liquid Glass 設計方向的本機辭典工具，介面與預設釋義使用繁體中文。提供 SwiftUI 原生 iOS App 與網頁版，可查詞、按主題學習，或完成一輪隨機複習。原生 App 使用系統 Liquid Glass；網頁使用相應的透明控制層與系統選單，已移除 Material 3。

| 目錄                              | 內容                                                 |

| [`web/`](web/README.md)           | 網頁源碼、生成網站、網頁測試與構建工具               |
| [`mobile/`](mobile/README.md)     | iOS 原生 App、Xcode 工程及原生測試                   |

| `deploy/`                         | VPS 發布、完整性檢查與回退                           |
| `scripts/`、`tests/`              | 跨端資料同步、打包及部署／資料一致性測試             |

`database/runtime/` 是詞庫和音訊的共用來源。Web 的 `web/dist/` 和 App 的 `mobile/ios/Mots/Resources/` 都由工具生成客戶端副本；不要分別修改兩端生成資料。

## iPhone App

原生工程位於 [`mobile/ios/Mots.xcodeproj`](mobile/ios/Mots.xcodeproj)，最低 iOS 26。一般 iPhone 使用單欄，Duo 與較寬視窗由 `NavigationSplitView` 自適應目錄／內容分欄；詞條位置和進度由獨立狀態管理，不依賴畫面寬度。

```sh
make ios-assets
open mobile/ios/Mots.xcodeproj
```

在 Xcode 選擇自己的簽名 Team 和 iPhone 後 Run。工程包含離線詞庫、單字讀音、卡片／列表、搜尋、隨機複習、熟悉程度、JSON 辭典匯入、網頁版備份合併及生詞 CSV 匯出。詳見 [iOS 構建、安裝及驗證說明](mobile/ios/README.md)。本機工程與未簽名構建不等於已安裝至手機、TestFlight 發布或 App Store 上架。

## 線上網站

開啟 [Mots 線上版](https://mots.feizhang233.com/)，即可使用完整詞庫及音訊。網站部署在東京 VPS，使用 HTTPS，並已設定開機自動啟動。部署與更新方式見 [deploy/README.md](deploy/README.md)。

在 App 和網站的設定開啟「進度同步」，一端建立配對碼，另一端輸入一次即可自動同步，無需註冊。未配對時仍只保存在本機；本機檔案版請先備份，再到線上網站還原及配對。

詞庫與 VPS 版本同步使用 `make build`、`make sync-vps`；發布前強制核對單元 JSON／Excel、網頁及 App 內置詞庫，部署後核對伺服器與公網 SHA-256。公開版本清單為 [`database/content-version.json`](https://mots.feizhang233.com/database/content-version.json)，本次結果見 [同步驗證](qa/repository-layout.md)。已安裝 App 目前隨新構建更新詞庫；配對後的個人熟悉程度與單字刪除／還原狀態另外透過 HTTPS 自動同步。

## GitHub 版本

原始碼、詞庫及讀音檔保存在此倉庫。可直接使用 [Releases 中的離線網頁或完整包](https://github.com/feizhang233/Mots/releases/latest)；`Mots-offline.html` 為單檔網頁，`Mots-complete.zip` 包含專案、資料庫與離線版。單檔網頁及壓縮包由打包程式生成，放在 Release 附件，不作為一般 Git 檔案提交。

[`database/`](database/) 包含法語第 1–16 單元共 3,846 詞的 JSON 與 Excel，以及 414 詞的日語詞彙總表，並提供檔案校驗清單。日語原表保存在 `database/japanese/source.md`，結構化資料保存在 `database/japanese/vocabulary.json`。詞庫採用靜態檔案；配對同步服務使用 Python 標準庫與私人 SQLite 存檔。自行匯入的辭典及設定仍保存在本機，可在設定下載備份。

## 使用

雙擊 `Mots法语词库.html` 即可使用；內建辭典與音訊已包含在單文件中。點 Mots 標誌會回到真正的首頁，不會開啟資料夾。首頁可搜尋目前辭典、查看進度或選擇學習方式。

- **切換辭典：** 在「設定 → 目前辭典」選擇辭典。同一語言可有多部辭典，每部的分類、詞條與熟悉程度各自保存。法語手冊共 3,846 詞，德語示例共 12 詞；日語詞彙總表共 414 詞，已替換原有 12 個日語示例，保留原表讀音、中文釋義與待確認標記。
- **使用方式：** 在搜尋左側的下拉選單切換查詞典、主題學習與隨機複習。只有 Mots 標誌提供返回首頁的入口；手機及側欄收合時，頁首保留 Mots 連結。
- **查詞典：** 按字母順序顯示單字、目前設定的釋義及例句，可搜尋並分頁。查詞會包含已掌握詞，不套用背誦時的熟悉程度隱藏設定。
- **主題學習：** 左側大類可展開子類，並可收合整個目錄；手機使用分類目錄。卡片先回想再顯示答案，列表保留緊湊單行。支援正序與亂序。
- **列表切回卡片：** 從目前列表頁往後尋找未學習的單字，必要時從頭尋找；仍套用目前分類、搜尋、隱藏及排序。若都已標記，停在目前頁首詞條；卡片答案預設隱藏。
- **隨機複習：** 每輪最多 20 個不重複的未掌握詞，優先選不熟悉、有印象，再補入未學習。已掌握不列入；每次標記會前進一詞，完成後顯示本輪實際標記數並可換一組。這不是依時間安排的間隔複習系統。
- **熟悉程度：** 綠、橙、紅分別代表已掌握、有印象、不熟悉。再次點目前標記可清除。背誦可勾選要隱藏的程度，設定中也可預設隱藏已掌握。
- **讀音：** 單字左側只有一個揚聲器。「設定 → 發音方式」可選內建音訊優先、裝置語音或 Google 翻譯。自訂辭典沒有預先生成的音訊，使用對應語言的裝置語音或 Google。
- **每頁詞數：** 可選 10、20、50、100 詞，預設 20，設定會保存。搜尋、清除、頁碼及長內容仍可操作。
- **匯出生詞：** 下載入口統一在設定內。選目前辭典的一級／二級單元或全部單字，下載包含單字、釋義、例句、熟悉程度與單元資料的 CSV。生詞為未學習、不熟悉及有印象，不含已掌握。搜尋、隱藏、分頁和亂序不會縮小匯出範圍；沒有生詞時不產生空檔。

## 手機與網站進度同步

在任一端設定的「進度同步」建立配對碼，再於另一端輸入。請把配對碼視為私人憑證：持有者可以讀寫這組進度。App 將它存入 Keychain，網站只在本機儲存；備份不包含配對碼。

已配對且前景連線時，標記熟悉程度後自動同步，其他端約 5 秒內更新。離線可繼續學習，恢復連線或返回 App 後重試；設定會顯示狀態，亦可手動同步。首次配對合併兩端既有進度；舊記錄沒有先後資訊時採較高熟悉程度。之後清除或降低熟悉程度都會同步，並以修訂序號及固定平手規則解決衝突。斷開配對保留本機進度。

同步包含熟悉程度與單字刪除／還原狀態，不包含學習位置、偏好或自訂辭典內容。內置詞庫兩端 ID 一致；自訂辭典需透過備份保留相同 ID，分別新建／匯入的同名辭典不會自動視為同一部。協議見 [`sync/PROTOCOL.md`](sync/PROTOCOL.md)。

列表可刪除不需要的單字：Web 使用最右側垃圾桶，App 向左側滑。刪除後可撤銷，也能在設定「辭典與生詞」內還原；原有熟悉程度保留。已配對的新版本會同步刪除與還原，舊 App 需更新後才會隱藏已刪除單字。

## 本機辭典與語言

設定中更換的是辭典，而非只改語言名稱。設定仍可獨立選擇釋義語言：繁體中文、簡體中文、英語、法語、德語、日語。缺少所選語言的釋義會明確提示，不會憑切換選項產生完整翻譯。日文詞條與例句保留日文寫法，不套用中文簡繁轉換。

可在設定匯入新辭典 JSON，指定名稱、背誦語言、詞條及可選的分類。支援法語、德語、日語；每份最多 2 MB／5,000 詞，本機最多 20 部自訂辭典。也可擴充目前辭典的詞條。下載的範本提供可編輯格式。原書內容、數量與來源以 `web/dist/data.js` 及介面即時統計為準。

## 儲存與備份

未配對的資料儲存在目前瀏覽器；配對後，同一辭典／詞條 ID 的熟悉程度自動跨端合併。法語內建辭典沿用 `mots.progress.v1`；德語、日語沿用各自的原進度鍵。新辭典使用獨立的辭典進度鍵，辭典庫使用 `mots.dictionaries.v1`，設定仍使用 `mots.settings.v2`，舊擴充詞條保留相容性。

新版備份包含自訂辭典、各部進度、設定及擴充詞條，仍可還原舊版法語與三語備份。還原接受 50 MB 以內的 JSON，會先驗證，再合併相同 ID 的內容；其他既有辭典及進度保留。瀏覽器容量不足時會保留當頁資料、顯示未儲存提示並建議下載備份；清除瀏覽器資料會清除本機進度與匯入內容。

## 開發與驗證

Web 維護來源位於 `web/src/`，原生 App 按 App／Features／Data／Sync 分層；`sync/` 分離協議、儲存和 HTTP。完整目錄與修改入口見 [程式結構](docs/architecture.md)。`web/dist/` 是生成網站。修改來源後執行：

```sh
make build
make test
make serve
```

開啟 `http://localhost:4173`。一般構建只需要 Python 3.11+ 與 Node.js 20+，不下載套件；`make check` 會確認來源與成品一致。

- `web/src/js/`：應用入口、共享工具、辭典／詞條驗證、音訊、下載和畫面渲染。
- `web/src/styles/`：共用 Liquid Glass 主題／版面、原生 Select、首頁與複習樣式。
- `web/src/components/`：原生 Select 的共用選項同步。
- `mobile/ios/`：SwiftUI App、Xcode 工程、詞庫匯出器和原生邏輯測試。
- `scripts/`：跨端詞庫核對、公開資料快照及完整離線包產生器。
- `web/tests/`：導航、詞典隔離、匯入備份、複習、卡片續讀與音訊測試。
- `tests/`：跨端資料一致性與部署回退測試。
- `deploy/`：VPS 設定、完整清單校驗、啟用及失敗回退。
- `sync/`：配對協議、私人 SQLite、HTTP 服務與限制。
- `database/`：原書 JSON／工作簿；`qa/`：驗證紀錄。

日語詞表按原 Markdown 左欄由上至下、再接右欄的順序匯入，依 `database/japanese/scenarios.json` 分為 10 個使用場景，每詞只歸一類且保留穩定 ID。詞條顯示原表的「詞彙（讀音）」，原表未提供的例句和詞性留空。「溶く〔待確認〕」保留原註記；新詞使用獨立且穩定的 ID，避免沿用示例詞的背誦進度。修改原表後執行 `python3 scripts/import-japanese.py`，再執行 `make build`；以 `python3 scripts/import-japanese.py --check` 核對結構化資料與 `web/src/js/languages.js`。

詳見 [程式結構與維護方式](docs/architecture.md)。原書來源見 [詞庫來源與校訂](docs/vocabulary-sources.md)；音訊限制見 [AUDIO.md](AUDIO.md)，介面約定見 [DESIGN.md](DESIGN.md) 與 [UX-CONTRACT.md](UX-CONTRACT.md)。

`make help` 列出常用入口；`make test-web`、`make test-sync`、`make test-tools` 可分別驗證各層，`make ios-check` 驗證原生程式與工程登記。單獨執行 `make` 仍預設構建。

## 離線版本

```sh
make package
```

重新生成單文件 HTML 與上級目錄 ZIP；內嵌音訊並檢查腳本語法、音訊簽名、Base64 和 ZIP 完整性。完整包包含來源、構建／部署工具及回歸測試，音訊只收錄目前清單引用的檔案。

瀏覽器本機資料仍以網址來源區隔；跨端同步需先配對，從本機／舊離線版轉移時使用設定中的備份與還原。自動檢查不等同真人聽辨或實機手機測試。
