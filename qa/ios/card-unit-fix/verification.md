# 手机 App 单元进度与卡片模式修复验证

日期：2026-10-23（Europe/Belgrade）。本次验证对象为 `mobile/ios/` 原生 SwiftUI App。

## 修复结果

1. 列表的掌握统计使用所选一级／二级单元的完整词条集合；搜索和隐藏已掌握不会改变统计分母。
2. 卡片底部原来的位置数字改为「選擇熟悉程度」及三个固定选项，保留前后导航。
3. 卡片选择任意熟悉程度后自动进入下一词，下一张答案隐藏。旧存档中关闭自动翻卡也不会阻止该行为；重选相同等级保留等级。
4. 卡片不显示搜索、筛选和列表控制区；卡片／列表切换位于顶部学习方式菜单。列表搜索在卡片中暂停，回到列表后恢复。
5. 卡片顶部仅一行进度条与「当前词序/当前卡组词数」，不再显示整部词典的标题和统计区。

卡片数字表示当前卡组位置；列表统计表示单元掌握数。隐藏已掌握会减少卡组词数，完整单元掌握统计的分母保持不变。列表标记不触发卡片自动翻页。最后一张学习卡保持在有效边界；随机复习保留完成页。

## Xcode 与模拟器实测

- Xcode 27.0（27A266a）。在 Xcode → Settings → Components 点击 Get 下载并安装 iOS 27.0，下载大小约 8.05 GB。
- 已安装运行环境：iOS 27.0，构建 24A434。
- 新建测试设备：Mots Test iPhone 17，UDID `424C5997-DD1B-491B-8234-662857C02CBD`。
- 在 Xcode 工程中选择该运行目标并点击 Run。最终源码已由 Xcode 构建、安装并在模拟器内运行。此版本 Xcode 的模拟器窗口由 Device Hub 提供。
- 一级目录「履歷、個人信息」：显示已掌握 0，共 321 词，而非整部词典的 3,846 词。
- 二级目录「個人數據」：列表显示已掌握 0，共 28 词；切换卡片显示 1/28。
- 揭示 `l’âge` 答案后选择「不熟悉」→ `âgé, âgée`，2/28，答案隐藏。
- 选择「有印象」→ `s’appeler`，3/28；选择「已掌握」→ `la dame`，4/28。每次只前进一词，卡片中无搜索或筛选区域。
- 从顶部菜单选择「列表模式」：显示已掌握 1，共 28 词，三个标记分别保留为不熟悉、有印象、已掌握。
- 开启「隱藏已掌握」：列表剩 27 词，但完整单元统计仍显示已掌握 1，共 28 词。
- 切回卡片后 `la dame` 为 3/27；将其标记已掌握后直接进入相邻的 `demeurer`，3/26，没有额外跳过单词。
- 在 Xcode 停止并再次 Run：恢复 `demeurer`、3/26、答案隐藏状态。
