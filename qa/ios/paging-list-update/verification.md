# 卡片翻页、列表熟练度与图标更新

2026-10-23，Xcode 27.0 / iOS 27.0 / Mots Test iPhone 17。本文对应用户随后提供的两张截图及新的六项要求，取代先前「卡片底部熟悉程度选择」界面要求。

## 已完成

- 删除卡片中的「先回想意思，再看看答案。」提示。
- 删除卡片的熟悉程度选择区及其标题；熟练度只在列表中操作。保留答案按钮、单词状态和前后翻页按钮。
- 使用原生 UIPageViewController pageCurl，支持从页面左右边缘交互翻页；长答案仍可垂直滚动。仅完成翻页才提交当前位置；邻页预加载不写进度，也不显示当前页的答案。系统「减少动态效果」使用滑动过渡。
- 列表删除截图 2 的模式／辞典标题／语言／掌握进度统计块。目录单元名保留；全部范围使用「全部單字」。
- 每列直接显示红色「不熟悉」、黄色「有印象」、绿色「已掌握」，包含文字、选中边框和可访问性状态；不再收进省略号。再次点击当前等级可清除，开启隐藏已掌握时立即移除已掌握词。另有独立的卡片按钮。
- 修复原图标生成黑方块的问题；新的绿色书本图标为不透明 RGB、1024×1024 PNG，已有 AppIcon 资源配置直接打包。系统负责外轮廓圆角。
