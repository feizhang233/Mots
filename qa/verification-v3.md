# v3 瀏覽器驗證

日期：2026-10-22。實現負責人在 Codex 內建瀏覽器測試 1280×720、390×844、320×700 三種視口；以下是實測結果，不代表真實手機裝置或逐條人工聽辨。

| 流程 | 結果 |
|---|---|
| 緊湊桌面列表 | 樣本列高精確為 52px；20 列有 20 個單字揚聲器，例句揚聲器為 0。卡片僅有 1 個揚聲器。 |
| 搜尋 | 初始欄位隱藏，點放大鏡展開；繁中「年齡」找到 2 詞。Escape 收合並保留查詢。 |
| 正序與亂序 | 正序切到亂序後，首詞變為 honnête；該篩選情境的 319／321 詞計數維持，再切正序可恢復原順序。 |
| 隱藏程度 | 勾選已掌握立即更新結果，重新整理仍保留設定。將 la dame 標為已掌握後即時移除，焦點轉到下一詞。全數隱藏時提供恢復按鈕。 |
| 手機分類 | 選擇子類後關閉分類對話框。390px 視口的隱藏選單水平邊界為 128–362px。 |
| 320px 版面 | document.scrollWidth 與 innerWidth 都為 320，沒有水平溢出；設定面板寬 296px，內容可捲動。 |
| 獨立語言設定 | 德語＋英語釋義、日語＋繁中釋義正常；日語「年齢」保持原文。語言設定切換與重新整理後保留。法語缺少英語釋義時顯示「尚無英語釋義」。 |
| 三語音訊 | HTMLAudio 實際進入 paused=false，時長有效：法語 1.346757 秒、德語 0.882358 秒、日語 0.789478 秒。這是播放器狀態檢查。 |
| 匯入錯誤 | 在獨立 localhost 測試來源，語言不符及損壞 JSON 均被拒絕，詞庫未變。 |
| 匯入與備份 | 有效日語「圖書館」匯入後示例庫由 12 增至 13 詞；標記 3 級後，v2 備份包含自訂詞與 rating=3。透過實際還原介面，v2 與 v1 分別成功合併 1 詞進度。 |
| 記錄輸出 | 應用程式 console 警告 0、錯誤 0。 |

另已修正長自訂 ID 的備份往返保留與新增詞後的亂序順序重建。語言支援代理的 VM 檢查通過每語言 5,000 詞的累計上限，以及別名釋義欄位的 1,600 字限制；這些屬程式檢查，不是瀏覽器或人工聽辨證據。

五個 JavaScript 語法檢查與嚴格靜態審計另列於 `premium-ui.json`／`premium-audit.json`。官方 design.md lint 曾因 DNS 無法使用，未宣稱通過。音訊簽名、解碼、波形和媒體播放狀態各有不同檢查範圍，不能據此保證所有發音的自然度或教學準確性。
