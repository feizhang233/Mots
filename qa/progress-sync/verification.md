## 真實客戶端操作

Xcode 27.0 成功構建並運行 Mots Test iPhone 17（iOS 27.0），配對新的內建瀏覽器網站頁面，使用正式 HTTPS 服務：

1. App 建立配對碼，網站加入，兩端顯示已同步；網站合併模擬器原有 4 個標記。
2. Web 將 l’âge 從黃色改為綠色，模擬器自動顯示已掌握。
3. 模擬器改回黃色，Web 自動顯示有印象。
4. 模擬器再次點擊黃色清除，Web 顯示未學習，三色均未選取。
5. 刷新 Web，Xcode 停止並重新 Run App：配對保留，清除的標記沒有復原。
6. 模擬器恢復測試前黃色，Web 自動跟隨；兩端斷開臨時配對，確認本機進度保留。

此測試不代表已將使用者的真實瀏覽器與實體手機配對；使用者需在兩端設定輸入同一配對碼。
