# 詞庫資料

這裡保存法語手冊第 1–16 單元的靜態詞庫，共 **3,846 個詞條**，以及 **414 詞的日語詞彙總表**。每個法語 `unitN/` 資料夾包含一份 JSON 與一份 XLSX，合計 32 份法語資料檔。

| 單元 | 詞條數 | 單元 | 詞條數 |
|---|---:|---|---:|
| 1 履歷、個人信息 | 321 | 9 感覺和運動 | 248 |
| 2 居住 | 196 | 10 學習培訓 | 153 |
| 3 環境 | 210 | 11 工作領域 | 157 |
| 4 旅遊和交通 | 167 | 12 語言 | 309 |
| 5 膳食 | 104 | 13 業餘時間和娛樂 | 304 |
| 6 購物 | 162 | 14 私人關係和聯絡 | 166 |
| 7 公共和私人服務業 | 131 | 15 政治和社會 | 334 |
| 8 身體健康和衛生 | 207 | 16 一般性概念 | 677 |

JSON 的 `words` 陣列包含詞條 ID、分類／子類、法語、中文、例句、詞性、基礎／進階級別、原書／PDF 頁碼、來源與校對註記。XLSX 保留可篩選的原書轉錄版本（含舊例句）；當前改寫例句以 JSON 為準。 內容來源與校正限制保留在各檔案的註記中。檔名與來源文字依原整理檔保留，網站介面以繁體中文顯示。

共用執行期詞庫來源是 [`runtime/data.js`](runtime/data.js)，音訊與對應清單也歸 `runtime/` 管理。Web 構建複製至 `web/dist/`，App 生成器複製至 `mobile/ios/Mots/Resources/`。此處的單元 JSON 供資料交換與維護使用，不會因修改 XLSX 而自動更新詞庫。發布時強制核對 16 份 JSON 的全部詞條欄位與執行期詞庫，並保留詞條 ID，避免既有進度錯配。

本目錄提供靜態詞庫資料，沒有另設資料庫伺服器或個人進度 API。`unit1/`–`unit16/` 是來源 JSON／Excel；`runtime/` 是兩端共用內容；`catalog.json`／`content-version.json` 是生成並發布的跨端快照。

`make build` 產生 [`catalog.json`](catalog.json) 和 [`content-version.json`](content-version.json)。前者與 iOS App 內置詞庫逐位元組相同，包含法語 3,846 詞、德語示例 12 詞及日語 414 詞；後者記錄內容版本、辭典數量、來源檔和快照 SHA-256。`make check` 及 VPS 發布準備會核對所有 JSON 欄位、詞條 ID 和法語來源檔的雜湊，發現不一致即停止。執行 `make sync-vps` 可將同一快照部署至 VPS 並驗證線上結果；具體流程見 [部署說明](../deploy/README.md)。

## 日語詞彙總表

[`japanese/source.md`](japanese/source.md) 保留使用者提供的原始 Markdown；[`japanese/vocabulary.json`](japanese/vocabulary.json) 是對應的結構化詞庫。共 414 詞，依左欄由上至下、再接右欄的順序排列，依使用場景分為 10 類，分類由 `japanese/scenarios.json` 按穩定詞條 ID 維護，替換原有 12 個日語示例。顯示文字保留原表「詞彙（讀音）」和「溶く〔待確認〕」標記；中文釋義原樣保留，原表未提供詞性。另由 [`japanese/examples.json`](japanese/examples.json) 為每詞補充一條原創日語例句及繁體中文參考翻譯；這些補充不屬於原始 Markdown，網站例句顯示日語原文。

場景分類為：日常起居與居家（35）、身體健康與醫療（19）、交通出行與旅行（29）、自然環境與動植物（59）、學校學習與研究（38）、職場工作與科技（45）、金錢金融與購物（19）、人際關係與情緒（51）、文化休閒與公共生活（58）、時間安排與狀態描述（61）。每詞只歸入一類；原始順序、詞條 ID、讀音、釋義與例句保留，已有學習進度繼續對應。

執行 `python3 scripts/import-japanese.py` 可由原表、例句補充檔及場景分類重建 JSON 與 `web/src/js/languages.js` 中的日語詞庫及分類；`python3 scripts/import-japanese.py --check` 可核對三者是否一致。新詞 ID 由詞彙及讀音產生，與舊示例 ID 分開，避免既有進度套用到不同詞條。讀音使用 Kyoko（ja-JP）合成語音，詳細範圍見 [讀音方案](../AUDIO.md)。

[`manifest.json`](manifest.json) 記錄各單元數量、32 份來源檔案的大小及 SHA-256，可用來核對下載內容。這批來源檔共 4,012,037 bytes；清單檔、本說明與生成的公開快照不計入其中。

## 日語語法筆記

`japanese/grammar/` 原樣保存使用者提供的 `01 普通語法背誦.md` 和 `02 語法類型整理.md`，並由 `scripts/import-japanese-grammar.py` 生成 `books.json` 與共用語法來源。兩本書的課次不重複：普通語法書 `grammar-ja` 僅包含第 1–26 課的 141 條、288 個例句；主題語法書 `grammar-theme-ja` 僅包含第 27–43 課，共 17 課、212 條語法／綜合運用小卡與 17 條區分方法筆記，合計 229 個學習項目、424 個例句。主題書不再收錄第 1–26 課。原普通稿的 186 條與 378 個例句完整保存在原始 Markdown 中，其中後段 45 條、90 個例句已由主題書對應課程完整收錄，匯入時會核對例句與翻譯。保留條目的 ID 不變，兩本書分別保存熟悉程度與刪除狀態。

原文提供的接續、補充用法、例句及中文翻譯均保留；主題表格中的連結補入普通語法的完整內容，各類另外撰寫的綜合用法與例句維持原文。沒有翻譯的例句不另行補寫。日語說明內的漢字不套用中文簡繁轉換。`make build` 重建語法內容，`make check` 及發布檢查核對來源與生成結果；內容版本與發布清單涵蓋兩份原稿及 `books.json`。

本資料夾不包含瀏覽器內的熟悉程度、個人匯入辭典或使用設定。這些內容仍由網站儲存在目前瀏覽器，可透過「設定 → 備份」另行保存。

來源為《法语基础词汇分类学习手册》，未將來源內容另行宣告為 MIT 或其他開放授權。

## 法語關聯例句（2026-10-25）

3,846 個法語詞條的當前 JSON 例句已改為另行編寫的學習內容；每句至少記錄兩個實際使用的其他詞條與句中詞形。`french/example-network.json` 保存完整例句、主要子句的時態、關聯 ID、原書例句及統計。`exampleRelated` 是資料關聯，不會新增介面導覽按鈕；單詞與語法透過句中共同出現形成複習網路。

一般現在時約占一半，其餘依情境採用複合過去時、未完成過去時、未來時、條件式和命令式等。原有詞條 ID、釋義、分類與頁碼保留，既有學習進度繼續對應。單元 XLSX 保留原書轉錄（包含舊例句），目前例句以 JSON 為準；舊例句另存於關聯檔案的 `originalText`。舊例句錄音引用已移除，單詞錄音照常保留。

維護：`python3 scripts/update-french-examples.py --input 完整例句JSON` 更新來源、執行期詞庫、來源清單與關聯圖；`--check` 核對完整覆蓋、去重、有效關聯、時態比例與來源一致性，然後依正常構建／發布流程更新。
