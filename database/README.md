# 詞庫資料

這裡保存法語手冊第 1–16 單元的靜態詞庫，共 **3,846 個詞條**。每個 `unitN/` 資料夾包含一份 JSON 與一份 XLSX，合計 32 份資料檔。

| 單元 | 詞條數 | 單元 | 詞條數 |
|---|---:|---|---:|
| 1 履歷、個人信息 | 321 | 9 感覺和運動 | 248 |
| 2 居住 | 196 | 10 學習培訓 | 153 |
| 3 環境 | 210 | 11 工作領域 | 157 |
| 4 旅遊和交通 | 167 | 12 語言 | 309 |
| 5 膳食 | 104 | 13 業餘時間和娛樂 | 304 |
| 6 購物 | 162 | 14 私人關係和聯絡 | 166 |
| 7 公共和私人服務業 | 131 | 15 政治和社會 | 334 |
| 8 身體健康和衛生 | 207 | 16 一般性概念 | 677 |

JSON 的 `words` 陣列包含詞條 ID、分類／子類、法語、中文、例句、詞性、基礎／進階級別、原書／PDF 頁碼、來源與校對註記。XLSX 提供可篩選的表格版本；內容來源與校正限制保留在各檔案的註記中。檔名與來源文字依原整理檔保留，網站介面以繁體中文顯示。

網站實際載入的是 [`dist/data.js`](../dist/data.js)，此處的單元 JSON 供資料交換與維護使用，不會因修改 XLSX 而自動更新網站。發布時已驗證：16 份 JSON 的 3,846 個 ID 均唯一，且法語、中文、例句、分類、子類與網站詞庫完全一致。更新資料時應同步維護這些來源與執行期資料，保留詞條 ID 以避免既有進度錯配。

[`manifest.json`](manifest.json) 記錄各單元數量、32 份檔案的大小及 SHA-256，可用來核對下載內容。這批資料檔共 2,296,609 bytes；清單檔與本說明不計入其中。

本資料夾不包含瀏覽器內的熟悉程度、個人匯入辭典或使用設定。這些內容仍由網站儲存在目前瀏覽器，可透過「設定 → 備份」另行保存。

來源為《法语基础词汇分类学习手册》，未將來源內容另行宣告為 MIT 或其他開放授權；第三方介面元件的授權見 [`scripts/vendor/material-select/`](../scripts/vendor/material-select/)。
