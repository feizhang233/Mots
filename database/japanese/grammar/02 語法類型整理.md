# 日語語法類型整理筆記

以「一個類型包含數個語法」為整理單位。先看本類有哪些句型，再比較意思、接續、語氣與使用限制；句型的完整背誦條目可從連結開啟。

共 43 個類型。類型 1 至 26 按意思與表達功能整理，類型 27 至 32 按句型形式整理，類型 33 至 43 按句子構成與使用規則整理。同一句型可以屬於多個類型，例如「～ざるを得ない」同時涉及不得已、古語形式與否定結構。

逐條記憶請使用[普通語法背誦](01%20%E6%99%AE%E9%80%9A%E8%AA%9E%E6%B3%95%E8%83%8C%E8%AA%A6.md)；本篇保留同類句型的區分方法，以及綜合運用的說明和例句。

### 類型 01 時間、契機與緊接發生

| 本類語法 | 背誦提示 |
| --- | --- |
| [～際（に）](01%20%E6%99%AE%E9%80%9A%E8%AA%9E%E6%B3%95%E8%83%8C%E8%AA%A6.md#001-際に) | 在……的時候；趁……之際。 |
| [～に際して](01%20%E6%99%AE%E9%80%9A%E8%AA%9E%E6%B3%95%E8%83%8C%E8%AA%A6.md#002-に際して) | 在……之際。 |
| [～にあたって](01%20%E6%99%AE%E9%80%9A%E8%AA%9E%E6%B3%95%E8%83%8C%E8%AA%A6.md#003-にあたって) | 在開始……之前／之際。 |
| [～たとたん（に）](01%20%E6%99%AE%E9%80%9A%E8%AA%9E%E6%B3%95%E8%83%8C%E8%AA%A6.md#004-たとたんに) | 剛一……就……。 |
| [～かと思うと／～かと思ったら](01%20%E6%99%AE%E9%80%9A%E8%AA%9E%E6%B3%95%E8%83%8C%E8%AA%A6.md#005-かと思うとかと思ったら) | 剛……就……；才覺得……便……。 |
| [～か～ないかのうちに](01%20%E6%99%AE%E9%80%9A%E8%AA%9E%E6%B3%95%E8%83%8C%E8%AA%A6.md#006-かないかのうちに) | 剛……就……；還沒完全……就……。 |

> **備註｜區分方法**
>
> - **際に**：正式地說「……的時候」，不一定是重大事件。
>  
> - **に際して**：著重重要事件或特殊場合「發生之際」。
>  
> - **にあたって**：著重開始新階段時的準備與態度，常用於積極、計畫性的事情。
>  
> - **たとたんに**：前項完成的瞬間，突然出現後項。
>  
> - **かと思うと／かと思ったら**：著重觀察到的快速變化，常有前後反差。
>  
> - **か～ないかのうちに**：著重時間間隔極短，幾乎同時發生。
>

| [～ばかりだ](01%20%E6%99%AE%E9%80%9A%E8%AA%9E%E6%B3%95%E8%83%8C%E8%AA%A6.md#009-ばかりだ) | 一直……；越來越……。 |
| [～一方だ](01%20%E6%99%AE%E9%80%9A%E8%AA%9E%E6%B3%95%E8%83%8C%E8%AA%A6.md#010-一方だ) | 不斷……；越來越……。 |
| [～（よ）うとしている](01%20%E6%99%AE%E9%80%9A%E8%AA%9E%E6%B3%95%E8%83%8C%E8%AA%A6.md#011-ようとしている) | 正要……；即將……。 |
| [～つつある](01%20%E6%99%AE%E9%80%9A%E8%AA%9E%E6%B3%95%E8%83%8C%E8%AA%A6.md#012-つつある) | 正在逐漸……。 |
| [～つつ](01%20%E6%99%AE%E9%80%9A%E8%AA%9E%E6%B3%95%E8%83%8C%E8%AA%A6.md#013-つつ) | 一邊……一邊……。 |

> **備註｜區分方法**
>
> - **最中に**：強調「正在做某事的當中」。
>  
> - **うちに**：強調「趁狀態還沒變」，或「過程中自然產生變化」。
>  
> - **ばかりだ／一方だ**：都表示單向變化；「ばかりだ」較常帶有負面感受，「一方だ」較中性。
>  
> - **（よ）うとしている**：即將發生，處於開始前的階段。
>  
> - **つつある**：已經開始變化，正在發展中。
>  
> - **つつ**：兩個動作同時進行；加上「ある」後，才表示變化正在發展。
>

| [～た上で〔先後順序〕](01%20%E6%99%AE%E9%80%9A%E8%AA%9E%E6%B3%95%E8%83%8C%E8%AA%A6.md#015-た上で先後順序) | ……之後再……。 |

| [～て以来](01%20%E6%99%AE%E9%80%9A%E8%AA%9E%E6%B3%95%E8%83%8C%E8%AA%A6.md#017-て以来) | 自從……以來。 |
| [～てこのかた](01%20%E6%99%AE%E9%80%9A%E8%AA%9E%E6%B3%95%E8%83%8C%E8%AA%A6.md#018-てこのかた) | 自從……以來一直……。 |
| [～てからでないと／～てからでなければ](01%20%E6%99%AE%E9%80%9A%E8%AA%9E%E6%B3%95%E8%83%8C%E8%AA%A6.md#019-てからでないとてからでなければ) | 不先……就不能……。 |

> **備註｜區分方法**
>
> - **てはじめて**：重點是「經歷之後才明白／才實現」。
>  
> - **た上で**：重點是「先完成準備，再進行下一步」。
>  
> - **次第**：重點是「一完成，就立即採取行動」。
>  
> - **て以来／てこのかた**：都表示從過去持續至今；「てこのかた」更強調這段期間一直如此。
>  
> - **てからでないと**：重點是必要條件——「沒有前項，就無法進行後項」。
>

### 類型 04 代表、範圍與限度

| 本類語法 | 背誦提示 |
| --- | --- |
| [～をはじめ（として）](01%20%E6%99%AE%E9%80%9A%E8%AA%9E%E6%B3%95%E8%83%8C%E8%AA%A6.md#020-をはじめとして) | 以……為代表；……以及其他……。 |
| [～からして](01%20%E6%99%AE%E9%80%9A%E8%AA%9E%E6%B3%95%E8%83%8C%E8%AA%A6.md#021-からして) | ① 光從……就……：以某個線索作為判斷依據；② 連……都……：舉出基本或局部的例子，暗示整體也如此。 |
| [～にわたって](01%20%E6%99%AE%E9%80%9A%E8%AA%9E%E6%B3%95%E8%83%8C%E8%AA%A6.md#022-にわたって) | 長達……；遍及……。 |
| [～を通じて／～を通して](01%20%E6%99%AE%E9%80%9A%E8%AA%9E%E6%B3%95%E8%83%8C%E8%AA%A6.md#023-を通じてを通して) | ① 在整個……期間：某種狀態持續存在；② 透過……：以某人、某事或某種途徑為媒介。 |
| [～限り（は）〔條件持續〕](01%20%E6%99%AE%E9%80%9A%E8%AA%9E%E6%B3%95%E8%83%8C%E8%AA%A6.md#024-限りは條件持續) | 只要……就……。 |
| [～だけ〔盡可能〕](01%20%E6%99%AE%E9%80%9A%E8%AA%9E%E6%B3%95%E8%83%8C%E8%AA%A6.md#025-だけ盡可能) | 盡可能……；做到能力或條件所允許的最大程度。 |

> **備註｜區分方法**
>
> - **をはじめ**：列舉「代表」，暗示還有其他同類事物。
>  
> - **からして**：從一個線索推斷，或用「連這一點都如此」暗示整體。
>  
> - **にわたって**：強調涵蓋的範圍很長、很廣。
>  
> - **を通じて／を通して**：強調整段期間的持續性，或作為媒介的途徑；兩者多數情況可互換。
>  
> - **限り**：表示後項成立的條件範圍。
>  
> - **だけ**：表示能力、需要或意願所能達到的最大程度。
>

| [～に限って](01%20%E6%99%AE%E9%80%9A%E8%AA%9E%E6%B3%95%E8%83%8C%E8%AA%A6.md#028-に限って) | ① 偏偏在……：某個特定時刻出現不巧的事情；② 唯獨……不會……：因特別信任某人，而認為他不可能做出某事。 |

> **備註｜區分方法**
>
> - **に限り**：公告式限定——「只有這些對象適用」。
>

>  
> - **限りでは**：資訊範圍——「在我知道或查到的範圍內」。
>  
> - **に限って**：特殊例外——「偏偏這時候」，或「唯獨這個人不可能」。
>

> **備註｜區分方法**
>
> - **に限らず**：重點是擴大「適用範圍」。
>  
> - **のみならず**：正式地追加另一項，常見於書面語。
>  
> - **ばかりか**：後項更進一步，常帶有「甚至」的感覺。
>  
> - **はもとより**：前項理所當然，主要要說的是後項「也如此」。
>  
> - **上に**：累加同方向的評價或情況——好上加好、壞上加壞。
>

| [～につけて](01%20%E6%99%AE%E9%80%9A%E8%AA%9E%E6%B3%95%E8%83%8C%E8%AA%A6.md#048-につけて) | 每當……就……。 |

> **備註｜區分方法**
>
> - **につれて／にしたがって**：前項越變，後項也逐漸變化，例如「年齡增長 → 體力下降」。此用法的後項通常不用命令、請求或意志表達。
>  
> - **に伴って／とともに**：前項發生或改變，後項也隨之發生；不一定強調逐步變化，例如「制度改變 → 手續也改變」。
>  
> - **次第だ**：強調結果由什麼決定，例如「是否比賽 → 取決於天氣」。與第 3 組的「動詞ます形＋次第」不同，後者表示「一……就立刻……」。
>  
> - **に応じて**：強調配合條件作出調整，例如「學生程度不同 → 使用不同教材」；後項常是有意識的選擇或安排。
>  
> - **につけて**：強調某件事反覆觸發感受，例如「每次聽到歌曲 → 想起往事」，不表示程度逐漸變化。

> **備註｜區分方法**
>

>

| [～といっても](01%20%E6%99%AE%E9%80%9A%E8%AA%9E%E6%B3%95%E8%83%8C%E8%AA%A6.md#068-といっても) | 雖說……，但其實……。 |

> **備註｜區分方法**
>
> - **にもかかわらず**：結果違反預期。例如「充分準備 → 卻沒有表現好」。注意：少了「も」的 **にかかわらず** 是「不管……」，意思不同。
>  
> - **ものの／とはいうものの**：承認前項，但補充尚未解決的問題或現實限制。例如「買了電腦 → 卻還沒使用」。

>  
> - **といっても**：修正前項的程度或範圍。例如「會做飯 → 其實只會簡單料理」。
>  
> - **からといって**：否定由理由直接推出結論。例如「價格高 → 不一定品質好」。前項本身通常沒有被否定。

> **備註｜區分方法**
>
> - **としたら／とすれば／とすると**：先假設，再思考行動或推論結果。「としたら」較常接意願、疑問；「とすれば／とすると」較偏向推論，三者有不少重疊。
>  
> - **となったら／となると**：著重「如果真的到了這個情況」，尤其是隨之出現的準備、問題或判斷變化。

>  
> - **意向形＋ものなら**：假設某個動作一旦發生，就會帶來不利結果，例如「要是洩漏祕密，就會出事」。這裡的意向形不一定表示說話者真的想做。
>  
> - **ないことには**：強調必須先成立的條件或完成的動作，例如「不先試用，就無法判斷」。
>  
> - **を抜きにしては**：強調不能省略的人或要素，例如「沒有合作，就無法實現」。單獨的「を抜きにして」也可表示「省略……」，未必帶有不能成立的意思。
>  
> - **としても／にしても／にしろ／にせよ**：即使前項成立，後項仍不改變。例如「即使立刻出發，也來不及」。與單純假設的「としたら」相比，多了「即便如此，仍然……」的轉折。

### 類型 16 原因、理由與結果

| 本類語法 | 背誦提示 |
| --- | --- |
| [～によって](01%20%E6%99%AE%E9%80%9A%E8%AA%9E%E6%B3%95%E8%83%8C%E8%AA%A6.md#080-によって) | ① 由於……；因……而……；② 透過……；藉由……。 |
| [～ものだから／～もので／～もの](01%20%E6%99%AE%E9%80%9A%E8%AA%9E%E6%B3%95%E8%83%8C%E8%AA%A6.md#081-ものだからものでもの) | 因為……，所以……。 |
| [～おかげだ／～せいだ](01%20%E6%99%AE%E9%80%9A%E8%AA%9E%E6%B3%95%E8%83%8C%E8%AA%A6.md#082-おかげだせいだ) | ① おかげだ：多虧……；託……的福；② せいだ：都怪……；由於……。 |
| [～あまり／あまりの～に](01%20%E6%99%AE%E9%80%9A%E8%AA%9E%E6%B3%95%E8%83%8C%E8%AA%A6.md#083-あまりあまりのに) | 因為太……，以致……。 |
| [～につき](01%20%E6%99%AE%E9%80%9A%E8%AA%9E%E6%B3%95%E8%83%8C%E8%AA%A6.md#084-につき) | 因……；由於……。 |

> **備註｜區分方法**
>
> - **によって**：較客觀、正式地說明「什麼原因造成什麼結果」，也可表示手段。例如「大雨 → 道路封閉」「改善流程 → 減少錯誤」。
>  
> - **ものだから／もので／もの**：從個人立場解釋理由，常帶有「有這樣的情況，請理解」的語氣，後項通常不接命令、邀請或個人意志。
>  
> - **おかげだ／せいだ**：依說話者對結果的評價區分——好結果用「おかげ」，壞結果用「せい」。「おかげ」偶爾也可反諷地用於壞結果。
>  
> - **あまり／あまりの～に**：不只是一般原因，而是「程度過強」導致特殊結果。例如「太在意 → 失眠」「太高興 → 流淚」。後項通常不接希望、意志或要求。
>  
> - **につき**：公告式地交代當下原因，例如「裝修中 → 暫停營業」，一般不用於日常對話中的個人辯解。
>  
> - **注意其他用法**：「によって」還可表示「依……而不同」；「につき」還可表示「每……」。本組主要整理原因、理由的用法。

### 類型 17 理由、推斷與責任決心

| 本類語法 | 背誦提示 |
| --- | --- |
| [～ことだし](01%20%E6%99%AE%E9%80%9A%E8%AA%9E%E6%B3%95%E8%83%8C%E8%AA%A6.md#085-ことだし) | 既然……；再說也……。 |
| [～のことだから](01%20%E6%99%AE%E9%80%9A%E8%AA%9E%E6%B3%95%E8%83%8C%E8%AA%A6.md#086-のことだから) | 因為是……；以……一貫的作風來看。 |
| [～だけに](01%20%E6%99%AE%E9%80%9A%E8%AA%9E%E6%B3%95%E8%83%8C%E8%AA%A6.md#087-だけに) | 正因為……，所以格外……。 |
| [～ばかりに](01%20%E6%99%AE%E9%80%9A%E8%AA%9E%E6%B3%95%E8%83%8C%E8%AA%A6.md#088-ばかりに) | 就因為……，結果卻……。 |
| [～からには／～以上（は）／～上は](01%20%E6%99%AE%E9%80%9A%E8%AA%9E%E6%B3%95%E8%83%8C%E8%AA%A6.md#089-からには以上は上は) | 既然……，就……。 |

> **備註｜區分方法**
>
> - **ことだし**：提出促成決定或提議的一個理由，暗示還有其他理由。例如「雨停了，其他條件也合適 → 出門吧」。
>  
> - **のことだから**：根據熟悉的人物特徵作推測。例如「他一向守時 → 應該已經到了」。重點是「以他的作風來看」。
>  
> - **だけに**：原因使結果或感受更加突出。例如「經驗豐富 → 應對準確」「期待很久 → 取消後格外失望」，結果不限定好壞。
>  
> - **ばかりに**：某個原因造成壞結果，突出後悔、埋怨或不值得的感覺。例如「只因地址寫錯 → 收不到包裹」。
>  
> - **からには／以上（は）／上は**：把已成立的事實或決定當作前提，強調應有的責任與行動，例如「既然答應 → 就負責到底」。三者常可互換，「上は」通常更鄭重。
>  
> - **ことだし vs. からには**：「ことだし」較像順勢提出建議，語氣較柔和；「からには」強調既然已經如此，就必須承擔後果或履行責任。

### 類型 18 困難、不能與可能性

| 本類語法 | 背誦提示 |

| [～がたい](01%20%E6%99%AE%E9%80%9A%E8%AA%9E%E6%B3%95%E8%83%8C%E8%AA%A6.md#090-がたい) | 難以……；實在無法……。 |

| [～どころではない](01%20%E6%99%AE%E9%80%9A%E8%AA%9E%E6%B3%95%E8%83%8C%E8%AA%A6.md#059-どころではない) | 根本不是做……的時候；哪有餘裕……。 |
| [～得る／～得ない](01%20%E6%99%AE%E9%80%9A%E8%AA%9E%E6%B3%95%E8%83%8C%E8%AA%A6.md#094-得る得ない) | ① 得る：有可能……；② 得ない：不可能……。 |

> **備註｜區分方法**
>
> - **がたい**：心理、情感或判斷上難以做到，例如「難以相信」「難以原諒」，不是單純不會做。
>  
> - **わけにはいかない**：有能力做，但責任或立場不允許。例如「明天要發表 → 今晚不能玩太晚」。前接否定形時，表示「不能不做」。
>  
> - **かねる**：因立場、規定或困難而無法照辦，常用於正式拒絕，例如「無法回答個人資料相關問題」；也可表示難以判斷、難以下決定。
>  
> - **ようがない**：缺少方法或必要條件，即使想做也無從下手。例如「沒有聯絡方式 → 無從聯絡」。
>  
> - **どころではない**：有更緊迫的事情或狀況，沒有時間、心情或身體餘裕。例如「忙著趕期限 → 哪有空看電影」。
>  
> - **得る／得ない**：判斷事情是否可能發生。例如「事故可能發生」，不表示「會不會操作某項技能」。
>  
> - **注意「かねない」**：它不是「かねる」的普通否定意思，而是「有可能發生不好的事情」，例如「事故につながりかねない」。

>

| [～にほかならない](01%20%E6%99%AE%E9%80%9A%E8%AA%9E%E6%B3%95%E8%83%8C%E8%AA%A6.md#122-にほかならない) | 正是……；無非就是……。 |
| [～に越したことはない](01%20%E6%99%AE%E9%80%9A%E8%AA%9E%E6%B3%95%E8%83%8C%E8%AA%A6.md#123-に越したことはない) | 最好是……；能……自然更好。 |
| [～しかない／～よりほかない](01%20%E6%99%AE%E9%80%9A%E8%AA%9E%E6%B3%95%E8%83%8C%E8%AA%A6.md#124-しかないよりほかない) | 只能……；除了……之外別無辦法。 |
| [～べきだ／～べきではない](01%20%E6%99%AE%E9%80%9A%E8%AA%9E%E6%B3%95%E8%83%8C%E8%AA%A6.md#125-べきだべきではない) | ① べきだ：應該……；② べきではない：不應該……。 |

> **備註｜區分方法**
>
> - **ものだ**：陳述一般道理或普遍傾向，例如「進入新環境，人通常會不安」。
>  
> - **というものだ**：對具體情況下評價，例如「不說明就改計畫，實在不負責任」；比「ものだ」更像在評論眼前的事。
>  
> - **にすぎない**：降低或限定程度，重點是「只有這麼多，沒有更多」。
>  
> - **にほかならない**：強調認定，重點是「正是這個，而不是其他」。例如同樣談「努力的結果」，它突出肯定；「にすぎない」則突出限定。
>  
> - **に越したことはない**：說明最理想的選項，但沒有強烈要求一定要做到。
>  
> - **しかない／よりほかない**：說明其他選項不存在，通常是情況迫使人如此做。
>  
> - **べきだ／べきではない**：依道理或價值判斷提出應當或不應當的行動，語氣比「ほうがいい」強。
>  
> - **注意否定位置**：「するべきではない」是不應該做；要表達「必須做」，通常用「するべきだ」，不要混成「しないべきだ」。

> **備註｜區分方法**
>
> - **（よ）うではないか**：號召大家一起行動，重點是共同參與。
>  
> - **ことだ**：根據具體目的提出建議，例如「想進步 → 每天朗讀」。
>  
> - **ものだ／ものではない**：依一般常識規勸，例如「受人幫助就應道謝」。
>  
> - **ことはない**：表示沒有必要，並非禁止。例如「不必急」，不等於「不准急」。
>

>  
> - **（よ）うか～まいか**：還在猶豫，尚未作出決定。
>  
> - **ものか**：比「まい」更突出情緒與反抗態度。
>  
> - **注意「ことだ」與「ものだ」**：本組是忠告、規勸用法；第 26 組還會出現感嘆、回憶等不同用法。

> **備註｜區分方法**
>
> - **てしかたがない／てしょうがない／てたまらない**：突出感受的強烈程度，例如「非常擔心」「餓得受不了」。「しょうがない」較口語。
>  
> - **てならない**：突出感受或想法自然湧現、揮之不去，常接「思える、感じられる、思い出される」等。
>  
> - **ないではいられない／ずにはいられない**：由內在感情驅動，忍不住採取行動，例如「忍不住笑」。
>  
> - **ないわけにはいかない**：受到責任、義理或立場約束，不能不做。

> - 描述特定他人的內心感受時，常加「ようだ／らしい／そうだ」等，避免直接斷言。

### 類型 26 願望、回憶與感嘆

| 本類語法 | 背誦提示 |

| [～ものがある](01%20%E6%99%AE%E9%80%9A%E8%AA%9E%E6%B3%95%E8%83%8C%E8%AA%A6.md#141-ものがある) | 有一種……的感覺；令人感到……。 |
| [～ことだ〔感嘆〕](01%20%E6%99%AE%E9%80%9A%E8%AA%9E%E6%B3%95%E8%83%8C%E8%AA%A6.md#142-ことだ感嘆) | 真是……啊。 |
| [～ことだろう／～ことか](01%20%E6%99%AE%E9%80%9A%E8%AA%9E%E6%B3%95%E8%83%8C%E8%AA%A6.md#143-ことだろうことか) | 多麼……啊；不知……了多少次。 |

**回憶與感嘆的對照**

**釋義：**  
① **回憶**：以前常常……。帶著懷念回顧過去反覆發生的事情。  
② **感嘆**：真是……啊。對某種狀況表達驚訝、感慨或讚嘆。

**接續：** 回憶用「動詞た形＋ものだ」；感嘆用「動詞／い形容詞普通形＋ものだ；な形容詞＋な＋ものだ」。

1. 学生のころは、友人と夜遅くまで語り合った**ものです**。

2. 卒業してからもう二十年ですか。時間がたつのは早い**ものですね**。

> **備註｜區分方法**
>
> - **たいものだ／てほしいものだ**：表達深切願望，前者是自己想做，後者是希望他人行動或事態改變。
>  
> - **たものだ**：懷念過去的習慣，不能只用來記錄一次性事件。
>  
> - **ものだ（感嘆）**：對事物或變化發出感慨，例如「時間過得真快」。
>  
> - **ないものか**：希望找到突破困難的方法，語氣像「難道不能設法做到嗎」。
>  
> - **ものがある**：指出某件事帶來深刻感受，例如「有令人感動之處」。
>  
> - **ことだ（感嘆）**：對具體事情作情緒性評價，例如「真令人感激」。
>  
> - **ことだろう／ことか**：配合「多麼、多少次」等，放大感情或數量。
>  
> - **注意同形異義**：「読むことだ」可表示忠告；「ありがたいことだ」則是感嘆。要看前項與語境。
>

### 類型 27 從原動詞理解語法〔原書 A 單元〕

**本類包含的語法：** [～に際して](01%20%E6%99%AE%E9%80%9A%E8%AA%9E%E6%B3%95%E8%83%8C%E8%AA%A6.md#002-に際して)、[～にあたって](01%20%E6%99%AE%E9%80%9A%E8%AA%9E%E6%B3%95%E8%83%8C%E8%AA%A6.md#003-にあたって)、[～にわたって](01%20%E6%99%AE%E9%80%9A%E8%AA%9E%E6%B3%95%E8%83%8C%E8%AA%A6.md#022-にわたって)、[～を通じて](01%20%E6%99%AE%E9%80%9A%E8%AA%9E%E6%B3%95%E8%83%8C%E8%AA%A6.md#023-を通じてを通して)、[～を通して](01%20%E6%99%AE%E9%80%9A%E8%AA%9E%E6%B3%95%E8%83%8C%E8%AA%A6.md#023-を通じてを通して)、[～に限って](01%20%E6%99%AE%E9%80%9A%E8%AA%9E%E6%B3%95%E8%83%8C%E8%AA%A6.md#028-に限って)、[～に関して](01%20%E6%99%AE%E9%80%9A%E8%AA%9E%E6%B3%95%E8%83%8C%E8%AA%A6.md#034-に関して)、[～をめぐって](01%20%E6%99%AE%E9%80%9A%E8%AA%9E%E6%B3%95%E8%83%8C%E8%AA%A6.md#035-をめぐって)、[～に対して](01%20%E6%99%AE%E9%80%9A%E8%AA%9E%E6%B3%95%E8%83%8C%E8%AA%A6.md#037-に対して)、[～にこたえて](01%20%E6%99%AE%E9%80%9A%E8%AA%9E%E6%B3%95%E8%83%8C%E8%AA%A6.md#038-にこたえて)、[～に基づいて](01%20%E6%99%AE%E9%80%9A%E8%AA%9E%E6%B3%95%E8%83%8C%E8%AA%A6.md#040-に基づいて)、[～に沿って](01%20%E6%99%AE%E9%80%9A%E8%AA%9E%E6%B3%95%E8%83%8C%E8%AA%A6.md#041-に沿って)、[～にしたがって](01%20%E6%99%AE%E9%80%9A%E8%AA%9E%E6%B3%95%E8%83%8C%E8%AA%A6.md#044-につれてにしたがって)、[～につれて](01%20%E6%99%AE%E9%80%9A%E8%AA%9E%E6%B3%95%E8%83%8C%E8%AA%A6.md#044-につれてにしたがって)、[～に伴って](01%20%E6%99%AE%E9%80%9A%E8%AA%9E%E6%B3%95%E8%83%8C%E8%AA%A6.md#045-に伴ってとともに)、[～に応じて](01%20%E6%99%AE%E9%80%9A%E8%AA%9E%E6%B3%95%E8%83%8C%E8%AA%A6.md#047-に応じて)、[～によって](01%20%E6%99%AE%E9%80%9A%E8%AA%9E%E6%B3%95%E8%83%8C%E8%AA%A6.md#080-によって)、[～において](01%20%E6%99%AE%E9%80%9A%E8%AA%9E%E6%B3%95%E8%83%8C%E8%AA%A6.md#144-において)、[～に先立って](01%20%E6%99%AE%E9%80%9A%E8%AA%9E%E6%B3%95%E8%83%8C%E8%AA%A6.md#145-に先立って)。

**1. ～に際して**

**釋義：** 在……之際。源於「際する」，表示面對重要事件或特殊場合。

**接續：** 名詞／動詞辭書形＋に際して。

1. 新しい事業を始める**に際して**、必要な手続きを確認しました。

2. 卒業**に際して**、お世話になった先生方に感謝を伝えました。

**2. ～にあたって**

**釋義：** 在開始……之際。源於「あたる」，強調開始某個階段時的準備或態度。

**接續：** 名詞／動詞辭書形＋にあたって。

1. 留学する**にあたって**、現地の生活について調べました。

2. 新製品の発売**にあたって**、説明会を開きます。

**3. ～にわたって**

**釋義：** 長達……；遍及……。源於「わたる」，強調時間或空間涵蓋的範圍。

**接續：** 表示範圍的名詞＋にわたって。修飾名詞時用「～にわたる＋名詞」。

1. 調査は三か月**にわたって**行われました。

2. 広い地域**にわたって**、交通への影響が出ています。

**4. ～を通じて**

**釋義：** 透過……；在整個……期間。源於「通じる」，表示媒介或貫穿整段期間。

**接續：** 名詞＋を通じて。

1. 地域の活動**を通じて**、多くの人と知り合いました。

2. この町では、一年**を通じて**さまざまな祭りが開かれます。

**5. ～を通して**

**釋義：** 透過……；在整個……期間。源於「通す」，表示以某個途徑或過程為媒介，也可表示全期間。

**接續：** 名詞＋を通して。

1. 実際の仕事**を通して**、専門知識を深めたいです。

2. 彼は生涯**を通して**、地域の教育に力を尽くしました。

**6. ～に限って**

**釋義：** 偏偏在……；唯獨……不可能……。源於「限る」，把特定的人或情況當作特殊例外。

**接續：** 名詞＋に限って。

1. 傘を持っていない日**に限って**、雨が降ります。

2. 約束を大切にする彼**に限って**、無断で休むはずがありません。

**7. ～に関して**

**釋義：** 關於……。源於「関する」，指定說明、調查等所涉及的話題。

**接續：** 名詞＋に関して。修飾名詞時用「～に関する＋名詞」。

1. 申請方法**に関して**、担当者に確認しました。

2. この制度**に関する**資料を読んでいます。

**8. ～をめぐって**

**釋義：** 圍繞……。源於「めぐる」，常用於議論、對立或競爭所圍繞的議題。

**接續：** 名詞＋をめぐって。修飾名詞時用「～をめぐる＋名詞」。

1. 新しい校則**をめぐって**、生徒と先生が意見を交わしました。

2. 土地の利用方法**をめぐる**議論が続いています。

**9. ～に対して**

**釋義：** 對……。源於「対する」，指出行動、態度或感情所面向的對象；也可表示對比。

**接續：** 名詞＋に対して。對比句也可用「普通形＋のに対して」。

1. 初めて来た人**に対して**、分かりやすく案内してください。

2. 都市部では人口が増えているの**に対して**、地方では減少しています。

**10. ～にこたえて**

**釋義：** 回應……；不辜負……。源於「応える」，表示針對要求、期待或聲援採取行動。

**接續：** 名詞＋にこたえて。

1. 利用者の要望**にこたえて**、開館時間を延長しました。

2. ファンの声援**にこたえて**、選手たちは最後まで走り続けました。

**11. ～に基づいて**

**釋義：** 根據……；依據……。源於「基づく」，以規定、資料或事實作為判斷和行動的依據。

**接續：** 名詞＋に基づいて。修飾名詞時用「～に基づく／に基づいた＋名詞」。

1. 調査結果**に基づいて**、改善案を作成しました。

2. 事実**に基づいた**説明をしてください。

**12. ～に沿って**

**釋義：** 沿著……；按照……。源於「沿う」，表示依循路線、方針或計畫。

**接續：** 名詞＋に沿って。修飾名詞時用「～に沿った＋名詞」。

1. 海岸**に沿って**、自転車で走りました。

2. 事前に決めた方針**に沿って**、作業を進めます。

**13. ～にしたがって**

**釋義：** 隨著……；遵照……。源於「従う」，可表示連動變化，也可表示依循指示或規則。

**接續：** 名詞／動詞辭書形＋にしたがって。

1. 標高が高くなる**にしたがって**、気温が下がります。

2. 係員の指示**にしたがって**、順番に移動してください。

**14. ～につれて**

**釋義：** 隨著……。源於「連れる」，表示前項逐漸變化，後項也自然隨之變化。

**接續：** 動詞辭書形／表示變化的名詞＋につれて。

1. 日本語に慣れる**につれて**、会話が楽しくなってきました。

2. 時間がたつ**につれて**、緊張が和らいできました。

**15. ～に伴って**

**釋義：** 伴隨……；隨著……。源於「伴う」，表示某件事發生時，同時帶來相應變化或影響。

**接續：** 名詞／動詞辭書形＋に伴って。

1. 利用者の増加**に伴って**、窓口を増やしました。

2. システムを変更する**に伴って**、操作方法も変わります。

**16. ～に応じて**

**釋義：** 根據……作相應調整。源於「応じる」，表示配合需求、程度或條件改變做法。

**接續：** 名詞＋に応じて。修飾名詞時用「～に応じた＋名詞」。

1. 予算**に応じて**、いくつかのプランをご提案します。

2. 子どもの成長**に応じた**運動を取り入れています。

**17. ～によって**

**釋義：** 由於……；透過……。與「よる」有關，可表示原因或方法，也有「依……而不同」等用法。

**接續：** 名詞＋によって。動作可用「普通形＋ことによって」。

1. 大雪**によって**、列車の運行に遅れが出ました。

2. 毎日記録をつけること**によって**、自分の変化が分かるようになりました。

**18. ～において**

**釋義：** 在……；於……。正式地指出事情發生的場所、領域或時期，常用於書面語。

**接續：** 名詞＋において。修飾名詞時用「～における＋名詞」。

1. 来週、第一会議室**において**説明会を開催します。

2. 教育**における**情報技術の役割について考えます。

**19. ～に先立って**

**釋義：** 在……之前，先……。源於「先立つ」，表示在主要事件開始前，先進行相關準備或活動，語氣正式。

**接續：** 名詞／動詞辭書形＋に先立って。修飾名詞時用「～に先立つ＋名詞」。

1. 工事を始める**に先立って**、近隣住民への説明会を開きました。

2. 開会式**に先立つ**リハーサルが、前日に行われます。

> **備註｜區分方法**
>
> - **に際して／にあたって／に先立って**：前兩者是「事件開始或發生之際」；「に先立って」明確表示在主要事件之前先做相關事情。
>  
> - **にわたって／を通じて／を通して**：「にわたって」突出涵蓋範圍；後兩者突出全期間或媒介，很多場合可互換。
>  
> - **に関して／をめぐって／に対して**：依次看「話題」「引發討論或爭議的核心」「行為對象或對比」。
>  
> - **にこたえて／に応じて**：前者回應期待或要求；後者按條件、程度作調整。
>  
> - **に基づいて／に沿って**：前者把資料、事實當依據；後者依循方針、計畫推進。
>  
> - **につれて／にしたがって／に伴って**：都可表示連動；「につれて」突出自然漸變，「に伴って」突出伴隨影響。「にしたがって」另可表示遵照指示，其他兩者沒有這個意思。
>  
> - **によって**：著重原因、方法等關係；**において**則指定場所、領域或時期，不能當作原因使用。
>  
> - 本組用原動詞幫助理解，但不能只靠字面意思判斷；接續與實際搭配仍需一起記憶。
>

### 類型 28 含「言う・する」的表達〔原書 B 單元〕

**本類包含的語法：** [～といった](01%20%E6%99%AE%E9%80%9A%E8%AA%9E%E6%B3%95%E8%83%8C%E8%AA%A6.md#052-といった)、[～といえば](01%20%E6%99%AE%E9%80%9A%E8%AA%9E%E6%B3%95%E8%83%8C%E8%AA%A6.md#065-といえば)、[～というと](01%20%E6%99%AE%E9%80%9A%E8%AA%9E%E6%B3%95%E8%83%8C%E8%AA%A6.md#066-というとといったら)、[～といったら](01%20%E6%99%AE%E9%80%9A%E8%AA%9E%E6%B3%95%E8%83%8C%E8%AA%A6.md#066-というとといったら)、[～といっても](01%20%E6%99%AE%E9%80%9A%E8%AA%9E%E6%B3%95%E8%83%8C%E8%AA%A6.md#068-といっても)、[～からといって](01%20%E6%99%AE%E9%80%9A%E8%AA%9E%E6%B3%95%E8%83%8C%E8%AA%A6.md#073-からといって)、[～とはいいながら](01%20%E6%99%AE%E9%80%9A%E8%AA%9E%E6%B3%95%E8%83%8C%E8%AA%A6.md#146-とはいいながら)、[～からして](01%20%E6%99%AE%E9%80%9A%E8%AA%9E%E6%B3%95%E8%83%8C%E8%AA%A6.md#021-からして)、[～としたら／～とすれば／～とすると](01%20%E6%99%AE%E9%80%9A%E8%AA%9E%E6%B3%95%E8%83%8C%E8%AA%A6.md#074-としたらとすればとするととなったらとなると)、[～にしても／～にしろ](01%20%E6%99%AE%E9%80%9A%E8%AA%9E%E6%B3%95%E8%83%8C%E8%AA%A6.md#079-としてもにしてもにしろにせよ)、[～にしては](01%20%E6%99%AE%E9%80%9A%E8%AA%9E%E6%B3%95%E8%83%8C%E8%AA%A6.md#096-にしては)、[～にしたら／～にすれば](01%20%E6%99%AE%E9%80%9A%E8%AA%9E%E6%B3%95%E8%83%8C%E8%AA%A6.md#100-にしたらにすればにしてみればにしても)、[～からすると／～からいうと](01%20%E6%99%AE%E9%80%9A%E8%AA%9E%E6%B3%95%E8%83%8C%E8%AA%A6.md#147-からするとからいうと)。

**1. ～といった**

**釋義：** ……等這類。列舉代表性例子，再用後面的名詞概括類別。

**接續：** 名詞＋といった＋名詞。常用「AやBといったC」。

1. りんごやみかん**といった**果物を毎日食べています。

2. 京都や奈良**といった**歴史のある町を訪ねたいです。

**2. ～といえば**

**釋義：** 說到……。承接話題，聯想到相關事項，或藉此轉入另一個相關話題。

**接續：** 名詞等被引用的話題＋といえば。

1. 秋**といえば**、紅葉を楽しみにしている人も多いでしょう。

2. 引っ越し**といえば**、新しい住所はもう決まりましたか。

**3. ～というと**

**釋義：** 一提到……就……。由某個提示詞引出典型印象，也可確認對方所指的內容。

**接續：** 名詞等被引用的內容＋というと。

1. 日本の冬**というと**、雪景色を思い浮かべます。

2. 来週の金曜日**というと**、二十日ですね。

**4. ～といったら**

**釋義：** 說到……，就要數……。引出代表性印象，較口語，也容易帶有強調或感情色彩。

**接續：** 名詞等被引用的話題＋といったら。

1. 夏の楽しみ**といったら**、やっぱり海で泳ぐことです。

2. この町のお土産**といったら**、あのお菓子が有名です。

**5. ～といっても**

**釋義：** 雖說……，但其實……。修正前項可能引起的過度理解，限制實際程度或範圍。

**接續：** 普通形＋といっても。名詞、な形容詞現在肯定形式的「だ」可省略。

1. 庭がある**といっても**、小さな花壇があるだけです。

2. 海外に住んだことがある**といっても**、三か月ほどです。

**6. ～からといって**

**釋義：** 不能因為……就……。承認理由存在，但否定僅憑這個理由就作出某種結論或行動。

**接續：** 普通形＋からといって。名詞、な形容詞現在肯定形式用「だからといって」。

1. 安い**からといって**、必要のない物まで買うべきではありません。

2. 経験者だ**からといって**、何でも一人でできるわけではありません。

**7. ～とはいいながら**

**釋義：** 雖說……，但實際上……。先承認某種說法或事實，再指出實際情況與預期不同。

**接續：** 普通形＋とはいいながら。名詞、な形容詞現在肯定形式的「だ」可省略。

1. 春**とはいいながら**、朝晩はまだ暖房が必要です。

2. 慣れた仕事**とはいいながら**、最後まで気を抜くことはできません。

**8. ～からして**

**釋義：**  
① 光從……就……：把某個線索當作推測依據。  
② 連……都……：以基本或局部例子暗示整體。

**接續：** 名詞＋からして。

1. 彼の表情**からして**、結果はあまりよくなかったようです。

2. このホテルは、入口**からして**豪華です。

**9. ～としたら／～とすれば／～とすると**

**釋義：** 假如……；假設……。把前項當作假設或推論前提，考慮後項的行動、結果或問題。

**接續：** 普通形＋各形式。名詞、な形容詞現在肯定形式用「だとしたら／だとすれば／だとすると」。

1. 一週間自由に旅行できる**としたら**、どこへ行きたいですか。

2. 一人千円かかる**とすると**、十人で一万円になりますね。

**10. ～にしても／～にしろ**

**釋義：** 即使……也……；無論……都……。接受前項假設後，後項判斷仍然成立；也可與疑問詞搭配，表示不論哪種情況。

**接續：** 普通形＋にしても／にしろ。名詞、な形容詞現在肯定形式通常不加「だ」。

1. 忙しい**にしても**、短い返事ぐらいはできるでしょう。

2. 何を選ぶ**にしろ**、自分でよく考えて決めてください。

**11. ～にしては**

**釋義：** 以……來說，卻……。以某個具體條件或事實為標準，評價實際結果出乎意料。

**接續：** 名詞／動詞普通形＋にしては。な形容詞可用「である＋にしては」。

1. この時計は、千円**にしては**よくできています。

2. 一人で準備した**にしては**、ずいぶん立派な会場ですね。

**12. ～にしたら／～にすれば**

**釋義：** 站在……的立場來看。設想他人的處境，推測其想法、需求或感受。

**接續：** 表示人物或群體的名詞＋にしたら／にすれば。

1. 親**にしたら**、子どもが遠くで一人暮らしをするのは心配でしょう。

2. 店側**にすれば**、急なキャンセルは困るはずです。

**13. ～からすると／～からいうと**

**釋義：** 從……來判斷；就……而言。指定判斷的線索、評價角度或立場。

**接續：** 名詞＋からすると／からいうと。

1. 足跡の大きさ**からすると**、かなり大きな動物のようです。

2. 使いやすさ**からいうと**、こちらの製品のほうが優れています。

> **備註｜區分方法**
>
> - **といった**：列舉例子並概括類別，後面接名詞。
>  
> - **といえば／というと／といったら**：都能引出聯想。「といえば」常用來承接、轉換相關話題；「というと」也可確認所指內容；「といったら」較容易帶有強調或情緒。
>  
> - **といっても／とはいいながら**：前者常縮小程度或範圍；後者著重「雖承認這樣說，但實際情況有轉折」。
>  
> - **からといって**：否定從理由直接推出結論，常接「とは限らない」「わけではない」「べきではない」。
>  
> - **からして**：可由一點推測整體，也可表示「連基本的這點都如此」；後一種用法不能直接換成「からすると」。
>  
> - **としたら／とすれば／とすると**：提出假設；「としたら」較常接意願或疑問，「とすると」較常推算結果。
>  
> - **にしても／にしろ**：即使假設成立，後項仍然如此，帶有讓步；單純的「としたら」不一定有轉折。
>  
> - **にしては**：按條件評價，結果意外；**にしたら／にすれば**：站到他人的立場推測感受。
>  
> - **からすると／からいうと**：指定判斷依據或角度。「からすると」較常由線索推測；「からいうと」較常就某個面向評論，兩者有重疊。

### 類型 29 含古語形式的表達〔原書 C 單元〕

**本類包含的語法：** [～もかまわず](01%20%E6%99%AE%E9%80%9A%E8%AA%9E%E6%B3%95%E8%83%8C%E8%AA%A6.md#055-もかまわず)、[～を問わず](01%20%E6%99%AE%E9%80%9A%E8%AA%9E%E6%B3%95%E8%83%8C%E8%AA%A6.md#053-を問わず)、[～にかかわらず](01%20%E6%99%AE%E9%80%9A%E8%AA%9E%E6%B3%95%E8%83%8C%E8%AA%A6.md#054-にかかわらずに関わらず)、[～にもかかわらず](01%20%E6%99%AE%E9%80%9A%E8%AA%9E%E6%B3%95%E8%83%8C%E8%AA%A6.md#069-にもかかわらず)、[～ずじまいだ](01%20%E6%99%AE%E9%80%9A%E8%AA%9E%E6%B3%95%E8%83%8C%E8%AA%A6.md#106-ずじまいだ)、[～ずにはいられない](01%20%E6%99%AE%E9%80%9A%E8%AA%9E%E6%B3%95%E8%83%8C%E8%AA%A6.md#134-ないではいられないずにはいられない)、[～ざるを得ない](01%20%E6%99%AE%E9%80%9A%E8%AA%9E%E6%B3%95%E8%83%8C%E8%AA%A6.md#136-ざるを得ない)、[～べきだ／～べきではない](01%20%E6%99%AE%E9%80%9A%E8%AA%9E%E6%B3%95%E8%83%8C%E8%AA%A6.md#125-べきだべきではない)、[～まい／～ではあるまいか〔推測〕](01%20%E6%99%AE%E9%80%9A%E8%AA%9E%E6%B3%95%E8%83%8C%E8%AA%A6.md#116-まいではあるまいか)、[～まい〔否定意志〕](01%20%E6%99%AE%E9%80%9A%E8%AA%9E%E6%B3%95%E8%83%8C%E8%AA%A6.md#130-まいようかまいか否定意志與猶豫)、[～つつ](01%20%E6%99%AE%E9%80%9A%E8%AA%9E%E6%B3%95%E8%83%8C%E8%AA%A6.md#013-つつ)、[～つつある](01%20%E6%99%AE%E9%80%9A%E8%AA%9E%E6%B3%95%E8%83%8C%E8%AA%A6.md#012-つつある)、[～つつ（も）](01%20%E6%99%AE%E9%80%9A%E8%AA%9E%E6%B3%95%E8%83%8C%E8%AA%A6.md#072-つつも)、[～にせよ](01%20%E6%99%AE%E9%80%9A%E8%AA%9E%E6%B3%95%E8%83%8C%E8%AA%A6.md#079-としてもにしてもにしろにせよ)。

**1. ～もかまわず**

**釋義：** 不顧……；不在乎……。「ず」相當於現代日語的「ない」，表示沒有顧慮某事便採取行動。

**接續：** 名詞＋もかまわず；動詞普通形＋のもかまわず。

1. 彼は周囲の視線**もかまわず**、大声で歌い始めました。

2. 靴がぬれるの**もかまわず**、川に入って子犬を助けました。

**2. ～を問わず**

**釋義：** 不論……；不分……。「問わず」表示不把某項差異當作限制條件。

**接續：** 名詞＋を問わず。

1. この講座は、専門分野**を問わず**受講できます。

2. 国籍**を問わず**、地域に住む人なら誰でも参加できます。

**3. ～にかかわらず**

**釋義：** 無論……；不管……。前項條件如何，都不影響後項。

**接續：** 名詞＋にかかわらず；也常接「行くか行かないか」等選擇形式。

1. 結果**にかかわらず**、最後まで努力することが大切です。

2. 購入するかしないか**にかかわらず**、説明を聞くことができます。

**4. ～にもかかわらず**

**釋義：** 儘管……卻……。承認前項成立，實際結果卻與預期相反。

**接續：** 動詞／い形容詞普通形＋にもかかわらず；な形容詞＋である＋にもかかわらず；名詞可直接接，也可接「である」。

1. 何度も説明した**にもかかわらず**、同じ質問が繰り返されました。

2. 平日**にもかかわらず**、会場は大勢の人でにぎわっていました。

**5. ～ずじまいだ**

**釋義：** 終究沒有……就結束了。原本想做，卻未能實現，常有錯過機會的遺憾。

**接續：** 動詞ない形去掉ない＋ずじまいだ。「する」變為「せずじまいだ」。

1. 気になっていた展覧会は、結局見に行か**ずじまいでした**。

2. 旅行中は忙しくて、買った日記帳も使わ**ずじまいでした**。

**6. ～ずにはいられない**

**釋義：** 忍不住……；無法不……。受到感情、欲望或身體需要驅使，無法克制某個行動。

**接續：** 動詞ない形去掉ない＋ずにはいられない。「する」變為「せずにはいられない」。

1. その映像を見ると、笑わ**ずにはいられません**。

2. 彼女の努力を知っているので、応援せ**ずにはいられません**。

**7. ～ざるを得ない**

**釋義：** 不得不……。雖然不願意，但因客觀情況限制，只能採取某種行動。「ざる」是保留在固定表達中的古語否定形式。

**接續：** 動詞ない形去掉ない＋ざるを得ない。「する」變為「せざるを得ない」。

1. 参加者が集まらず、開催を延期せ**ざるを得ませんでした**。

2. ほかに交通手段がなく、歩いて帰ら**ざるを得ませんでした**。

**8. ～べきだ／～べきではない**

**釋義：** 應該……／不應該……。「べき」源於古語「べし」，用於表達道理、責任或適當行為。

**接續：** 動詞辭書形＋べきだ／べきではない。「する」可用「するべき／すべき」。

1. 約束したことは、最後まで守る**べきです**。

2. 確認していない情報を、事実として広める**べきではありません**。

**9. ～まい／～ではあるまいか〔推測〕**

**釋義：**  
① **まい**：大概不會……，相當於「ないだろう」。  
② **ではあるまいか**：不是……嗎；恐怕是……吧。以反問形式委婉提出推測。

**接續：** 動詞辭書形＋まい；一段動詞也可接ます形去掉ます。「ではあるまいか」可接名詞、な形容詞語幹，或「普通形＋の」。

1. この時間なら、店はもう開いてい**まい**。

2. 今回の問題は、連絡不足が原因**ではあるまいか**。

**10. ～まい〔否定意志〕**

**釋義：** 絕不……；決定不再……。與推測用法不同，表示說話者自己的決心。

**接續：** 動詞辭書形＋まい；一段動詞也可用ます形去掉ます。「する」可用「するまい／すまい」。

1. 二度と人の意見だけで進路を決める**まい**と誓いました。

2. これ以上、家族に心配をかけ**まい**と思っています。

**11. ～つつ**

**釋義：** 一邊……一邊……。保留古語形式，表示同一主體同時進行兩個動作，較正式。

**接續：** 動詞ます形去掉ます＋つつ。

1. 資料を読み返し**つつ**、説明の順番を考えました。

2. 相手の反応を見**つつ**、話す速さを調整しました。

**12. ～つつある**

**釋義：** 正在逐漸……。表示某種變化已開始，仍持續發展。

**接續：** 動詞ます形去掉ます＋つつある。

1. この地域では、古い町並みが失われ**つつあります**。

2. 新しい制度への理解が、少しずつ広がり**つつあります**。

**13. ～つつ（も）**

**釋義：** 雖然……卻……；明知……卻仍……。常表示認知、意願與行動不一致。

**接續：** 動詞ます形去掉ます＋つつ（も）。

1. 体によくないと知り**つつも**、夜遅くに食べてしまいます。

2. 連絡しなければと思い**つつ**、一週間が過ぎてしまいました。

**14. ～にせよ**

**釋義：** 即使……也……。「せよ」是「する」的命令形之一，但在此固定句型中表示讓步，不是命令。

**接續：** 普通形＋にせよ。名詞、な形容詞現在肯定形式通常不加「だ」。

1. 初めての経験**にせよ**、事前の準備は必要です。

2. 参加できない**にせよ**、連絡だけはしてください。

> **備註｜區分方法**
>
> - **ず**大致相當於「ない」，但各個固定句型的接續與意思仍須分別記憶。「する」常變為「せず」。
>  
> - **にかかわらず**是不受條件影響；**にもかかわらず**是結果違反預期，不能漏看「も」。
>  
> - **ずにはいられない**是內在衝動；**ざるを得ない**是外在情況迫使人如此做。
>  
> - **まい**要看主體及語境：自己的決心常是否定意志；對他人或事態的判斷常是否定推測。
>  
> - **つつ**可表示同時進行或轉折；**つつある**則表示變化正在發展。
>  
> - 古語來源有助於理解，但不代表可以隨意替換成現代形式。例如「ざるを得ない」不能直接改成「ないを得ない」。
>

### 類型 30 含「もの・こと」的表達〔原書 D 單元〕

**本類包含的語法：** [～ものか](01%20%E6%99%AE%E9%80%9A%E8%AA%9E%E6%B3%95%E8%83%8C%E8%AA%A6.md#061-ものか強烈否定)、[～というものではない](01%20%E6%99%AE%E9%80%9A%E8%AA%9E%E6%B3%95%E8%83%8C%E8%AA%A6.md#063-というものではないというものでもない)、[～ものの／～とはいうものの](01%20%E6%99%AE%E9%80%9A%E8%AA%9E%E6%B3%95%E8%83%8C%E8%AA%A6.md#070-もののとはいうものの)、[～ものなら](01%20%E6%99%AE%E9%80%9A%E8%AA%9E%E6%B3%95%E8%83%8C%E8%AA%A6.md#075-ものなら)、[～（よ）うものなら](01%20%E6%99%AE%E9%80%9A%E8%AA%9E%E6%B3%95%E8%83%8C%E8%AA%A6.md#076-ようものなら)、[～もので／～ものだから](01%20%E6%99%AE%E9%80%9A%E8%AA%9E%E6%B3%95%E8%83%8C%E8%AA%A6.md#081-ものだからものでもの)、[～もの〔句末理由〕](01%20%E6%99%AE%E9%80%9A%E8%AA%9E%E6%B3%95%E8%83%8C%E8%AA%A6.md#081-ものだからものでもの)、[～ものだ〔一般道理〕](01%20%E6%99%AE%E9%80%9A%E8%AA%9E%E6%B3%95%E8%83%8C%E8%AA%A6.md#119-ものだ一般道理)、[～というものだ](01%20%E6%99%AE%E9%80%9A%E8%AA%9E%E6%B3%95%E8%83%8C%E8%AA%A6.md#120-というものだ)、[～ものだ／～ものではない〔規勸〕](01%20%E6%99%AE%E9%80%9A%E8%AA%9E%E6%B3%95%E8%83%8C%E8%AA%A6.md#128-ものだものではない規勸)、[～たいものだ／～てほしいものだ](01%20%E6%99%AE%E9%80%9A%E8%AA%9E%E6%B3%95%E8%83%8C%E8%AA%A6.md#137-たいものだてほしいものだ)、[～たものだ〔回憶〕](01%20%E6%99%AE%E9%80%9A%E8%AA%9E%E6%B3%95%E8%83%8C%E8%AA%A6.md#138-たものだ回憶)、[～ものだ〔感嘆〕](01%20%E6%99%AE%E9%80%9A%E8%AA%9E%E6%B3%95%E8%83%8C%E8%AA%A6.md#139-ものだ感嘆)、[～ないもの（だろう）か](01%20%E6%99%AE%E9%80%9A%E8%AA%9E%E6%B3%95%E8%83%8C%E8%AA%A6.md#140-ないものだろうか)、[～ものがある](01%20%E6%99%AE%E9%80%9A%E8%AA%9E%E6%B3%95%E8%83%8C%E8%AA%A6.md#141-ものがある)、[～（のこと）となると](01%20%E6%99%AE%E9%80%9A%E8%AA%9E%E6%B3%95%E8%83%8C%E8%AA%A6.md#067-のこととなると)、[～ないことには](01%20%E6%99%AE%E9%80%9A%E8%AA%9E%E6%B3%95%E8%83%8C%E8%AA%A6.md#077-ないことには)、[～ことだし](01%20%E6%99%AE%E9%80%9A%E8%AA%9E%E6%B3%95%E8%83%8C%E8%AA%A6.md#085-ことだし)、[～のことだから](01%20%E6%99%AE%E9%80%9A%E8%AA%9E%E6%B3%95%E8%83%8C%E8%AA%A6.md#086-のことだから)、[～ことだ〔忠告〕](01%20%E6%99%AE%E9%80%9A%E8%AA%9E%E6%B3%95%E8%83%8C%E8%AA%A6.md#127-ことだ忠告)、[～ことはない](01%20%E6%99%AE%E9%80%9A%E8%AA%9E%E6%B3%95%E8%83%8C%E8%AA%A6.md#129-ことはない)、[～ことだ〔感嘆〕](01%20%E6%99%AE%E9%80%9A%E8%AA%9E%E6%B3%95%E8%83%8C%E8%AA%A6.md#142-ことだ感嘆)、[～ことだろう／～ことか](01%20%E6%99%AE%E9%80%9A%E8%AA%9E%E6%B3%95%E8%83%8C%E8%AA%A6.md#143-ことだろうことか)、[～こと〔指示〕](01%20%E6%99%AE%E9%80%9A%E8%AA%9E%E6%B3%95%E8%83%8C%E8%AA%A6.md#148-こと指示)、[～ことなく](01%20%E6%99%AE%E9%80%9A%E8%AA%9E%E6%B3%95%E8%83%8C%E8%AA%A6.md#149-ことなく)、[～ことに](01%20%E6%99%AE%E9%80%9A%E8%AA%9E%E6%B3%95%E8%83%8C%E8%AA%A6.md#150-ことに)、[～ことは～が](01%20%E6%99%AE%E9%80%9A%E8%AA%9E%E6%B3%95%E8%83%8C%E8%AA%A6.md#151-ことはが)、[～ということだ／～とのことだ〔傳聞〕](01%20%E6%99%AE%E9%80%9A%E8%AA%9E%E6%B3%95%E8%83%8C%E8%AA%A6.md#152-ということだとのことだ傳聞)。

**1. ～ものか**

**釋義：** 怎麼可能……；才不會……。以反問表達強烈否定，可否定可能性，也可表達拒絕的決心。

**接續：** 動詞／い形容詞普通形＋ものか；な形容詞／名詞＋な＋ものか。

1. 説明も聞いていないのに、分かる**ものか**。

2. こんなところで諦める**ものか**。

**2. ～というものではない**

**釋義：** 並不是……就一定……。反駁過於簡單的判斷，指出還需要考慮其他因素。

**接續：** 普通形＋というものではない。名詞、な形容詞現在肯定形式的「だ」可省略。

1. 時間をかければ、必ずよい作品ができる**というものではありません**。

2. 新しければ何でも便利だ**というものではありません**。

**3. ～ものの／～とはいうものの**

**釋義：** 雖然……，但是……。承認前項事實，同時指出現實限制或未達預期的結果。

**接續：** 動詞／い形容詞普通形＋ものの；な形容詞＋な＋ものの；名詞＋である＋ものの。「とはいうものの」接普通形，名詞等的「だ」可省略。

1. 申し込んだ**ものの**、まだ参加できるか分かりません。

2. 便利になった**とはいうものの**、使い方を覚えるのに時間がかかります。

**4. ～ものなら**

**釋義：** 如果能……的話。假設難以實現或可能性很低的事情，常伴隨願望或挑戰。

**接續：** 動詞可能形等＋ものなら。

1. 休める**ものなら**、一週間ぐらいゆっくり休みたいです。

2. 一人で直せる**ものなら**、やってみてください。

**5. ～（よ）うものなら**

**釋義：** 萬一……就會……。假設某個動作發生，便引起嚴重或不理想的結果。

**接續：** 動詞意向形＋ものなら。

1. この書類をなくそ**うものなら**、大変なことになります。

2. 授業中に居眠りし**ようものなら**、すぐに先生に注意されます。

**6. ～もので／～ものだから**

**釋義：** 因為……，所以……。說明個人原因，常有辯解或請求理解的語氣。

**接續：** 動詞／い形容詞普通形＋もので／ものだから；な形容詞／名詞＋な＋各形式。

1. 初めて来た**ものですから**、道がよく分かりませんでした。

2. 急な予定が入った**もので**、昨日は参加できませんでした。

**7. ～もの〔句末理由〕**

**釋義：** 因為……嘛。放在句末補充理由，常帶有解釋、辯解或撒嬌的語氣，偏口語。

**接續：** 普通形＋もの。常用「～んだもの／～んですもの」，口語可說「もん」。

1. 今日はもう帰りたい。朝からずっと働いていたんだ**もの**。

2. 一人で行くのは不安だよ。知らない場所なんだ**もの**。

**8. ～ものだ〔一般道理〕**

**釋義：** 本來就是……；一般總是……。陳述普遍性質、自然傾向或一般道理。

**接續：** 動詞辭書形／ない形＋ものだ；い形容詞＋ものだ；な形容詞＋な＋ものだ。

1. 新しいことを始めるときは、誰でも不安になる**ものです**。

2. 人の気持ちは、簡単には分からない**ものです**。

**9. ～というものだ**

**釋義：** 這才叫……；實在是……。根據常識或本質，對某種情況作出強調性評價。

**接續：** 普通形＋というものだ。名詞、な形容詞現在肯定形式的「だ」通常省略。

1. 相手の話も聞かずに決めつけるのは、不公平**というものです**。

2. 長年の努力が認められたのだから、苦労したかいがあった**というものです**。

**10. ～ものだ／～ものではない〔規勸〕**

**釋義：** 應該……／不應該……。依據一般道理、禮節或常識提出規勸。

**接續：** 動詞辭書形／ない形＋ものだ；動詞辭書形＋ものではない。

1. 人に何かを頼むときは、丁寧にお願いする**ものです**。

2. 他人の持ち物を、勝手に使う**ものではありません**。

**11. ～たいものだ／～てほしいものだ**

**釋義：** 真想……／真希望……。表達深切願望或一般性的期望。

**接續：** 動詞ます形去掉ます＋たいものだ；動詞て形＋ほしいものだ。

1. いつか自分の書いた本を出版してみ**たいものです**。

2. この美しい景色を、次の世代にも残し**てほしいものです**。

**12. ～たものだ〔回憶〕**

**釋義：** 以前常常……。懷念過去反覆發生的事情或習慣。

**接續：** 動詞た形＋ものだ。

1. 子どものころは、近くの山でよく遊んだ**ものです**。

2. 学生時代は、試験前になると図書館に通った**ものです**。

**13. ～ものだ〔感嘆〕**

**釋義：** 真是……啊。對事物、變化或結果表達驚訝、感慨或讚嘆。

**接續：** 動詞／い形容詞普通形＋ものだ；な形容詞＋な＋ものだ。

1. あんなに小さかった子が大学生になるとは、月日がたつのは早い**ものですね**。

2. こんな細かい違いによく気づいた**ものですね**。

**14. ～ないもの（だろう）か**

**釋義：** 難道不能……嗎；真希望能……。希望設法實現某件不容易做到的事。

**接續：** 動詞ない形＋もの（だろう）か，常接可能形或非意志動詞。

1. この待ち時間を、もう少し短くでき**ないものでしょうか**。

2. なくした写真が、どこかから見つから**ないものか**と思っています。

**15. ～ものがある**

**釋義：** 有令人……的地方；帶來一種……的感受。指出某事使人產生明顯、深刻的感覺。

**接續：** 動詞辭書形／ない形＋ものがある；い形容詞＋ものがある；な形容詞＋な＋ものがある。

1. 彼の言葉には、深く考えさせられる**ものがあります**。

2. 誰もいなくなった教室を見ると、寂しい**ものがあります**。

**16. ～（のこと）となると**

**釋義：** 一談到……；一涉及……就……。涉及特定話題或實際情況時，反應、態度或判斷有所改變。

**接續：** 名詞＋となると／のこととなると；動詞辭書形＋となると。

1. 彼は音楽の**こととなると**、何時間でも話し続けます。

2. 一週間なら楽しいですが、一年間住む**となると**、準備が必要です。

**17. ～ないことには**

**釋義：** 不先……就不能……。前項是後項成立的必要條件。

**接續：** 動詞ない形＋ことには。

1. 本人に確認し**ないことには**、本当の理由は分かりません。

2. 必要な資料がそろわ**ないことには**、審査を始められません。

**18. ～ことだし**

**釋義：** 既然……；再說也……。提出促成決定或提議的一個理由，暗示還有其他理由。

**接續：** 動詞／い形容詞普通形＋ことだし；な形容詞＋な＋ことだし；名詞＋の＋ことだし。

1. 全員そろった**ことだし**、そろそろ始めましょう。

2. 天気もいい**ことだし**、少し散歩しませんか。

**19. ～のことだから**

**釋義：** 以……一貫的作風來看。根據熟悉的人物性格或習慣推測其行動。

**接續：** 表示人物的名詞＋のことだから。

1. 慎重な彼の**ことだから**、何度も確認したはずです。

2. 面倒見のいい先生の**ことだから**、きっと相談に乗ってくれるでしょう。

**20. ～ことだ〔忠告〕**

**釋義：** 最好……；應該……。針對具體目的提出實用建議。

**接續：** 動詞辭書形／ない形＋ことだ。

1. 語彙を増やしたければ、覚えた言葉を実際に使う**ことです**。

2. 明日早く起きるなら、今夜は夜更かししない**ことです**。

**21. ～ことはない**

**釋義：** 不必……；沒有必要……。常用於安慰、鼓勵或勸告。

**接續：** 動詞辭書形＋ことはない。

1. 分からないことがあっても、恥ずかしがる**ことはありません**。

2. まだ締め切りまで一週間あるので、今日中に全部終える**ことはありません**。

**22. ～ことだ〔感嘆〕**

**釋義：** 真是……啊。對某件具體事情表達情緒性評價。

**接續：** い形容詞＋ことだ；な形容詞＋な＋ことだ。也可用「困ったことだ」等狀態表達。

1. 遠くからわざわざ来てくれるとは、ありがたい**ことです**。

2. 大切な連絡を忘れるなんて、困った**ことですね**。

**23. ～ことだろう／～ことか**

**釋義：** 多麼……啊；不知……了多少次。配合程度、數量疑問詞表達強烈感慨。

**接續：** 「どんなに／どれほど／何度」等＋普通形＋ことだろう／ことか。な形容詞現在肯定形式用「な／である」。

1. 久しぶりに家族に会えて、どんなにうれしかった**ことでしょう**。

2. この問題について、何度話し合った**ことか**。

**24. ～こと〔指示〕**

**釋義：** 必須……；不得……。用於規定、注意事項或書面指示。

**接續：** 動詞辭書形／ない形＋こと。

1. 申請書には、必ず連絡先を記入する**こと**。

2. 試験中は、携帯電話を使用しない**こと**。

**25. ～ことなく**

**釋義：** 沒有……而……；不……地……。相當於較正式的「ないで」，表示某個動作未發生，後項仍持續或進行。

**接續：** 動詞辭書形＋ことなく。

1. 彼は一度も振り返る**ことなく**、その場を去りました。

2. 選手たちは最後まで諦める**ことなく**、走り続けました。

**26. ～ことに**

**釋義：** 令人……的是。先表明對整件事情的感受，再敘述事實。

**接續：** い形容詞＋ことに；な形容詞＋な＋ことに；部分動詞た形＋ことに。

1. うれしい**ことに**、第一志望の大学に合格しました。

2. 驚いた**ことに**、会場で十年ぶりに友人と再会しました。

**27. ～ことは～が**

**釋義：** ……倒是……，但是……。先承認前項，接著強調限制或轉折，通常重複同一詞語。

**接續：** 普通形＋ことは＋同一表達＋が。な形容詞在「こと」前用「な」。

1. この料理は辛い**ことは**辛い**が**、とてもおいしいです。

2. 説明を読んだ**ことは**読んだ**が**、よく理解できませんでした。

**28. ～ということだ／～とのことだ〔傳聞〕**

**釋義：** 聽說……；據說……。轉述從他人、通知或報導得知的內容。「とのことだ」常用於較正式的轉達。

**接續：** 普通形＋ということだ／とのことだ。

1. 来月から開館時間が変わる**ということです**。

2. 田中さんは、少し遅れて到着する**とのことでした**。

> **備註｜區分方法**
>
> - **もの**常與感情、一般道理、願望或回憶有關；**こと**則也廣泛用於條件、忠告、指示、傳聞等。
>  
> - **ものなら**是假設難以實現的可能性；**意向形＋ものなら**是假設動作發生後會帶來不良結果。
>  
> - **ものだ**要看接續與語境：「たものだ」可回憶習慣；「するものだ」可陳述道理或規勸；評價語加「ものだ」也可感嘆。
>  
> - **ことだ**也要看前項：「毎日読むことだ」是忠告；「ありがたいことだ」是感嘆。
>  
> - **ことはない**是不必做；**ないことには**是不先做就不能成立；**ことなく**則描述沒有做前項。
>  
> - **ことに**先表明情緒，再敘述事實；**ことだろう／ことか**配合程度或數量詞加強感慨。
>  
> - **ということだ**除傳聞外，也可表示歸納、解釋所得的結論；須依資訊來源及上下文判斷。
>

### 類型 31 含「わけ・ところ」的表達〔原書 E 單元〕

**本類包含的語法：** [～わけがない](01%20%E6%99%AE%E9%80%9A%E8%AA%9E%E6%B3%95%E8%83%8C%E8%AA%A6.md#058-わけがない)、[～わけではない／～というわけではない](01%20%E6%99%AE%E9%80%9A%E8%AA%9E%E6%B3%95%E8%83%8C%E8%AA%A6.md#062-わけではないというわけではない)、[～わけにはいかない](01%20%E6%99%AE%E9%80%9A%E8%AA%9E%E6%B3%95%E8%83%8C%E8%AA%A6.md#091-わけにはいかないわけにもいかない)、[～ないわけに（は）いかない](01%20%E6%99%AE%E9%80%9A%E8%AA%9E%E6%B3%95%E8%83%8C%E8%AA%A6.md#135-ないわけにはいかない)、[～わけだ／～というわけだ](01%20%E6%99%AE%E9%80%9A%E8%AA%9E%E6%B3%95%E8%83%8C%E8%AA%A6.md#153-わけだというわけだ)、[～どころではない](01%20%E6%99%AE%E9%80%9A%E8%AA%9E%E6%B3%95%E8%83%8C%E8%AA%A6.md#059-どころではない)、[～どころか](01%20%E6%99%AE%E9%80%9A%E8%AA%9E%E6%B3%95%E8%83%8C%E8%AA%A6.md#060-どころか)、[～たところ](01%20%E6%99%AE%E9%80%9A%E8%AA%9E%E6%B3%95%E8%83%8C%E8%AA%A6.md#101-たところ)、[～ところだった](01%20%E6%99%AE%E9%80%9A%E8%AA%9E%E6%B3%95%E8%83%8C%E8%AA%A6.md#105-ところだった)、[～ところから／～ことから](01%20%E6%99%AE%E9%80%9A%E8%AA%9E%E6%B3%95%E8%83%8C%E8%AA%A6.md#154-ところからことから)。

**1. ～わけがない**

**釋義：** 不可能……。根據情況或常識，強烈否定可能性。

**接續：** 動詞／い形容詞普通形＋わけがない；な形容詞＋な＋わけがない；名詞＋の／である＋わけがない。

1. 何も練習していないのに、急に上手になる**わけがありません**。

2. 彼は今海外にいるので、ここにいる**わけがありません**。

**2. ～わけではない／～というわけではない**

**釋義：** 並不是……；並不意味著……。否定某個推論或過度概括。

**接續：** 「わけ」前用普通形，な形容詞用「な」、名詞用「の／である」；「というわけ」前接普通形，名詞等的「だ」可省略。

1. 忙しいですが、毎日残業している**わけではありません**。

2. 有名な店なら、必ずおいしい**というわけではありません**。

**3. ～わけにはいかない**

**釋義：** 不能……。並非能力不足，而是責任、立場或常識不允許。

**接續：** 動詞辭書形＋わけにはいかない。

1. 大切な資料なので、誰にでも見せる**わけにはいきません**。

2. 明日は試験があるので、今夜遅くまで遊ぶ**わけにはいきません**。

**4. ～ないわけに（は）いかない**

**釋義：** 不能不……；必須……。因責任、義理或現實需要而必須做。

**接續：** 動詞ない形＋わけに（は）いかない。

1. 自分が提案した計画なので、協力し**ないわけにはいきません**。

2. ここまでお世話になったのだから、お礼を言わ**ないわけにはいきません**。

**5. ～わけだ／～というわけだ**

**釋義：** 難怪……；也就是說……。根據新得知的理由理解結果，或從前項推導合理結論。

**接續：** 動詞／い形容詞普通形＋わけだ；な形容詞＋な＋わけだ；名詞＋の／な／である＋わけだ。「というわけだ」接普通形，名詞等的「だ」可省略。

1. 昨夜は二時間しか寝ていないんですか。それなら眠い**わけですね**。

2. 一日二ページなら、一か月で約六十ページ読める**というわけです**。

**6. ～どころではない**

**釋義：** 根本不是做……的時候；哪有餘裕……。有更緊迫的事情或身心限制，無法顧及前項。

**接續：** 動詞辭書形／名詞＋どころではない。

1. 引っ越しの準備で、旅行に行く**どころではありません**。

2. 頭が痛くて、仕事**どころではありませんでした**。

**7. ～どころか**

**釋義：** 別說……，反而……；不僅……，甚至……。實際情況與前項相反，或程度遠超前項。

**接續：** 動詞／い形容詞普通形＋どころか；な形容詞＋な＋どころか；名詞＋どころか。

1. 休む**どころか**、週末まで働くことになりました。

2. 彼は漢字を読める**どころか**、難しい文章もすらすら書けます。

**8. ～たところ**

**釋義：** 做了……之後，結果發現……。報告實際行動後得到的結果。

**接續：** 動詞た形＋ところ。

1. 日程を確認した**ところ**、会議は来週に変更されていました。

2. 店員に聞いてみた**ところ**、取り寄せができるそうです。

**9. ～ところだった**

**釋義：** 差一點就……。接近某個結果，但實際未發生。

**接續：** 動詞辭書形／ない形＋ところだった。

1. 急いでいたので、財布を家に忘れる**ところでした**。

2. 友人が教えてくれなければ、申し込みに間に合わない**ところでした**。

**10. ～ところから／～ことから**

**釋義：** 由於……；從……這一點來看。表示事件的原因、命名由來，或作出判斷的依據。

**接續：** 動詞／い形容詞普通形＋ところから／ことから；な形容詞＋な／である＋各形式；名詞通常用「である＋各形式」。

1. この山は富士山に似ている**ところから**、小富士と呼ばれています。

2. 電気がついていない**ことから**、まだ誰も来ていないと判断しました。

> **備註｜區分方法**
>
> - **わけがない**：強烈否定可能性；**わけではない**：只是否定某個推論，留下其他可能。
>  
> - **わけにはいかない**：不能做；**ないわけにはいかない**：不能不做。否定位置會改變結論。
>  
> - **わけだ**：知道理由後恍然大悟，或推出合理結果，例如「原來沒睡，難怪很睏」。
>  
> - **どころではない**：沒有餘裕；**どころか**：實際相反或程度更高。
>  
> - **たところ**：已做並發現結果；**辭書形＋ところだった**：差點發生卻沒發生。
>  
> - **ところから／ことから**都可表示依據或原因；命名由來、特徵說明常見「ところから」，「ことから」的使用範圍更廣。
>  
> - 「ところ」不一定表示地點；「わけ」也不一定直接翻成「理由」，應以整個句型理解。
>

### 類型 32 成對表達與助詞的特殊用法〔原書 F 單元〕

**本類包含的語法：** [～やら～やら](01%20%E6%99%AE%E9%80%9A%E8%AA%9E%E6%B3%95%E8%83%8C%E8%AA%A6.md#049-やらやら)、[～というか～というか](01%20%E6%99%AE%E9%80%9A%E8%AA%9E%E6%B3%95%E8%83%8C%E8%AA%A6.md#050-というかというか)、[～にしても～にしても／～にしろ～にしろ／～にせよ～にせよ](01%20%E6%99%AE%E9%80%9A%E8%AA%9E%E6%B3%95%E8%83%8C%E8%AA%A6.md#051-にしてもにしてもにしろにしろにせよにせよ)、[～だの～だの](01%20%E6%99%AE%E9%80%9A%E8%AA%9E%E6%B3%95%E8%83%8C%E8%AA%A6.md#155-だのだの)、[～か～ないかのうちに](01%20%E6%99%AE%E9%80%9A%E8%AA%9E%E6%B3%95%E8%83%8C%E8%AA%A6.md#006-かないかのうちに)、[～（よ）うか～まいか](01%20%E6%99%AE%E9%80%9A%E8%AA%9E%E6%B3%95%E8%83%8C%E8%AA%A6.md#130-まいようかまいか否定意志與猶豫)、[～とは](01%20%E6%99%AE%E9%80%9A%E8%AA%9E%E6%B3%95%E8%83%8C%E8%AA%A6.md#064-とは)、[～ぐらい／～くらい](01%20%E6%99%AE%E9%80%9A%E8%AA%9E%E6%B3%95%E8%83%8C%E8%AA%A6.md#107-ぐらいくらい)、[～など／～なんか／～なんて](01%20%E6%99%AE%E9%80%9A%E8%AA%9E%E6%B3%95%E8%83%8C%E8%AA%A6.md#108-などなんかなんて)、[～まで／～までして](01%20%E6%99%AE%E9%80%9A%E8%AA%9E%E6%B3%95%E8%83%8C%E8%AA%A6.md#109-までまでしててまで)、[～として～ない](01%20%E6%99%AE%E9%80%9A%E8%AA%9E%E6%B3%95%E8%83%8C%E8%AA%A6.md#110-としてない)、[～さえ](01%20%E6%99%AE%E9%80%9A%E8%AA%9E%E6%B3%95%E8%83%8C%E8%AA%A6.md#111-さえ)、[～のみ](01%20%E6%99%AE%E9%80%9A%E8%AA%9E%E6%B3%95%E8%83%8C%E8%AA%A6.md#156-のみ限定)。

**1. ～やら～やら**

**釋義：** 又是……又是……；……啦……啦。列舉多項情況，常帶有忙亂、困擾或複雜感受。

**接續：** 名詞／動詞辭書形／い形容詞＋やら＋同類形式＋やら。

1. 今日は会議**やら**来客**やら**で、落ち着いて仕事ができませんでした。

2. 初めての一人暮らしで、うれしい**やら**不安**やら**、複雑な気持ちです。

**2. ～というか～というか**

**釋義：** 該說是……還是……。提出兩種描述，一邊說一邊斟酌適當措辭。

**接續：** 名詞／普通形＋というか，重複使用。名詞、な形容詞現在肯定形式的「だ」常省略。

1. 彼の話し方は、丁寧**というか**慎重**というか**、とにかくゆっくりです。

2. あの部屋は、静か**というか**寂しい**というか**、不思議な雰囲気でした。

**3. ～にしても～にしても／～にしろ～にしろ／～にせよ～にせよ**

**釋義：** 無論……還是……都……。列舉不同情況，表示共同結論不變。

**接續：** 名詞／普通形＋各形式，重複使用。名詞、な形容詞現在肯定形式通常不加「だ」，な形容詞也可用「である」。

1. 買う**にしても**借りる**にしても**、まず予算を決めましょう。

2. 学生**にせよ**社会人**にせよ**、時間を守ることは大切です。

**4. ～だの～だの**

**釋義：** ……啦……啦。隨意列舉各種事物或說法，常帶有不耐煩、抱怨或覺得瑣碎的語氣。

**接續：** 名詞／普通形＋だの，重複使用。名詞、な形容詞現在肯定形式通常省略「だ」。

1. 机の上には、書類**だの**雑誌**だの**が積み重なっています。

2. 彼は忙しい**だの**疲れた**だの**と言って、片づけを手伝いません。

**5. ～か～ないかのうちに**

**釋義：** 剛……就……；還沒完全……就……。強調兩件事間隔極短，幾乎同時發生。

**接續：** 動詞辭書形＋か＋同一動詞ない形＋かのうちに。

1. 席に座る**か座らないかのうちに**、名前を呼ばれました。

2. 食事が終わる**か終わらないかのうちに**、子どもは遊びに出かけました。

**6. ～（よ）うか～まいか**

**釋義：** 做……還是不做……。在相反的兩個選項之間猶豫。

**接續：** 動詞意向形＋か＋同一動詞辭書形＋まいか。一段動詞後項也可用ます形去掉ます。

1. 本当のことを話そ**うか**話す**まいか**、迷いました。

2. 新しいパソコンを買お**うか**買う**まいか**、まだ決めていません。

**7. ～とは**

**釋義：** 所謂……是指……。用於解釋詞語、概念或本質。

**接續：** 名詞＋とは。後項常用「～ことだ／～ものだ」。

1. 「日帰り」**とは**、その日のうちに帰ってくることです。

2. 責任を持つ**とは**、自分の行動の結果を引き受けることです。

**8. ～ぐらい／～くらい**

**釋義：** ……這點程度；至少……。把前項看成程度輕、容易做到或最低限度的事情。

**接續：** 名詞／動詞／い形容詞普通形＋ぐらい／くらい；な形容詞＋な＋ぐらい／くらい。

1. 自分の予定**ぐらい**、自分で確認してください。

2. 少し失敗した**くらいで**、自信をなくす必要はありません。

**9. ～など／～なんか／～なんて**

**釋義：** ……之類的；像……這種……。本組用於輕視、認為不重要或自謙。「なんか／なんて」較口語。

**接續：** 名詞（＋助詞）＋など／なんか／なんて。

1. うわさ**など**、気にしないほうがいいですよ。

2. 私**なんて**、まだ勉強を始めたばかりです。

**10. ～まで／～までして**

**釋義：** 甚至連……也……；甚至不惜……。舉出超出預期的極端例子或手段。

**接續：** 名詞（＋助詞）＋まで；動作性名詞＋までして。動詞形式為「て形＋まで」。

1. この小さな店には、海外からのお客さん**まで**来ます。

2. 借金**までして**、高い車を買う必要があるのでしょうか。

**11. ～として～ない**

**釋義：** 連一……也沒有。以最小單位強調完全否定，毫無例外。

**接續：** 一＋量詞＋として＋否定表達。

1. その質問に、一人**として**答えられませんでした。

2. この一か月、一日**として**練習を休んでいません。

**12. ～さえ**

**釋義：**  
① 連……都……：舉出極端例子。  
② 只要……就……：指出足以成立的最低條件。

**接續：** 名詞（＋助詞）＋さえ；條件用法常配合「ば／なら／たら」。

1. 緊張しすぎて、自分の名前**さえ**うまく言えませんでした。

2. この番号**さえ**分かれば、予約を確認できます。

**13. ～のみ**

**釋義：** 僅……；只有……。限定對象、範圍或數量，相當於較正式的「だけ」。

**接續：** 本單元主要整理「名詞＋のみ」。修飾名詞時可用「～のみの＋名詞」。

1. この入口は、関係者**のみ**利用できます。

2. 土日**のみの**仕事を探しています。

> **備註｜區分方法**
>
> - **やら～やら／だの～だの**都可列舉多項事情；「だの」更容易帶有不耐煩或貶低感。
>  
> - **というか～というか**是斟酌描述同一事物；**にしても～にしても**則列舉情況，指出共同結論。
>  
> - **か～ないかのうちに**描述事情幾乎同時發生；**（よ）うか～まいか**描述是否行動的猶豫。
>  
> - **ぐらい**把事情看得輕或視為最低要求；**など**可降低其價值；**のみ**則只是正式限定，不一定帶評價。
>  
> - **まで／さえ**都能表示極端例子。「まで」突出超出預期的延伸；「さえ」常暗示其他情況更不用說。
>  
> - **さえ＋條件形**是「只要」，不能因看到「さえ」就一律翻成「連」。
>  
> - **一＋量詞＋として～ない**強調零例外，不能與表示身分的「教師として」混淆。
>

### 類型 33 後項語氣、人稱與正負面結果〔原書 G 單元〕

**本類包含的語法與形式：** ～次第、～ものなら、～からには、～ことだし、～たとたんに、～のことだから、～かねない、～おかげで等。

**1. 後項通常表達意志、希望或要求的句型**

**釋義：** 有些句型不只是連接事實，而是以某個條件或理由為基礎，提出接下來想做、應做或希望對方做的事情。

**接續與代表句型：**

- 動詞ます形去掉ます＋**次第**。

- 可能形等＋**ものなら**。

- 普通形＋**からには／以上（は）**；動詞辭書形／た形＋**上は**。

- 普通形等＋**ことだし**。

- 動詞て形＋**でも**。

1. 詳細が分かり**次第**、すぐにご連絡します。

2. 自分で引き受けた**からには**、最後まで責任を持って取り組みます。

**2. 後項通常敘述事實或結果，不接意志、命令的句型**

**釋義：** 有些句型用於描述自然發生、已觀察到或與預期不同的結果，通常不能直接接「しましょう」「してください」「したい」等。

**接續與代表句型：**

- 動詞た形＋**とたん（に）／かと思うと／かと思ったら／ところ／きり**。

- 動詞辭書形＋か＋ない形＋**かのうちに**。

- **もかまわず／にもかかわらず／ものの／ものだから**。

- **おかげで／せいで／あまり／だけに／ばかりに**。

- 假設推論用法的**とすると／となると**，後項通常偏向結果判斷。

1. ドアを開けた**とたんに**、猫が外へ飛び出しました。

2. 電話で確認した**ところ**、受付はすでに終了していました。

**3. 後項適合推測、判斷的句型**

**釋義：** 前項提供假設或人物特徵，後項推測會出現什麼情況，常見「だろう」「はずだ」「に違いない」等。

**接續與代表句型：** 動詞意向形＋**ものなら**；人物名詞＋**のことだから**。前者常推測不利結果，後者依人物特徵判斷。

1. 今ここで予定を変更し**ようものなら**、多くの人が困るでしょう。

2. 準備の早い彼の**ことだから**、もう必要な物はそろえているはずです。

**4. 第一人稱的感受、願望與不得已**

**釋義：** 描述內心感受或意願時，說話者通常直接陳述自己的狀態。若談特定他人的內心，往往需要資訊來源或推測標記。

**接續與代表句型：**

- **わけにはいかない／ないわけにはいかない／ざるを得ない**。

- **てしかたがない／てならない／ないではいられない／ずにはいられない**。

- **たいものだ**。

1. 明日の結果が気になっ**てしかたがありません**。

2. 彼女も故郷へ帰り**たいものだ**と思っているようです。

**5. 觀察他人情況的句型**

**釋義：** 有些句型重點是觀察外部跡象，再敘述他人的變化或推測其情況，不適合直接當作自己意志行動的說明。

**接續與代表句型：** 動詞た形＋**かと思うと／かと思ったら**；普通形＋**とみえる**。前者描述迅速變化，後者根據跡象推測。

1. 赤ちゃんは泣いた**かと思うと**、すぐに眠ってしまいました。

2. 彼は風邪を引いている**とみえて**、朝からせきばかりしています。

**6. 通常搭配負面結果的句型**

**釋義：** 某些句型本身就包含惡化、遺憾、風險、受限制等意味，後項需要與這種方向相符。

**接續與代表句型：**

- 變化動詞辭書形＋**ばかりだ**。

- **せいで／ばかりに／どころではない／あげく／ずじまいだ**。

- 動詞ます形去掉ます＋**かねない**。

- 動詞辭書形／ない形、名詞の形＋**おそれがある**。

- **一方だ**可表示負面變化，但也能表示正面變化，不能視為只限負面。

1. 説明を確認しなかった**ばかりに**、申し込みをやり直すことになりました。

2. このまま無理を続けると、体調を崩し**かねません**。

**7. 通常搭配正面評價的句型**

**釋義：** 某些句型用來表達擅長、感謝、慶幸或不負期待，通常與好的結果、能力或評價搭配。

**接續與代表句型：**

- 領域名詞＋**にかけては**。

- 普通形等＋**おかげで**。

- 普通形等＋**だけ（のことは）ある／だけあって**。

1. 記憶力**にかけては**、彼女にかなう人はいません。

2. 毎日練習してきた**だけあって**、発音がとても自然です。

> **備註｜區分方法**
>
> - 先判斷後項是在說**事實、意志、要求，還是推測**，不要只看中文意思是否通順。
>  
> - 「一……就……」可能是客觀結果，也可能是承諾行動：前者可考慮「たとたんに」，後者常用「次第」。
>  
> - 表示突然觀察到的變化時，不要直接接自己的計畫。例如「泣いたかと思うと眠った」是在描述變化。
>  
> - 第一人稱感受可直接說；描述特定他人的內心，通常用「ようだ／らしい／そうだ／と言っている」等交代依據。
>  
> - 「かねない」不能拿來表示期待中的好事；「おそれがある」也用於不希望發生的風險。
>  
> - 「おかげ」通常是好結果，但可反諷；「一方だ」則本來就能表示正面或負面變化。
>  
> - 這些是典型搭配與考題判斷原則，並非所有形式都只有一種用法。判斷時仍須確認句型在當句中的具體意思。

### 類型 34 句子構成與固定搭配〔原書第 2 部・第 1 課〕

**本類包含的語法與形式：** ～てからでないと、～からといって、～ないことには、～を抜きにしては、～として～ない、～さえ～ば、～といった、～をもとにして、～を中心として等。

**1. 需要與否定表達呼應的句型**

**釋義：** 有些句型提出必要條件、否定推論或排除可能性，後項通常必須接否定或「不能成立」的表達。

**接續：**

- 動詞て形＋**からでないと**＋不能、困難等。

- 名詞＋**に限って**＋はずがない等。

- 普通形＋**からといって**＋わけではない／とは限らない等。

- 動詞ない形＋**ことには**＋不能、困難等。

- 名詞＋**を抜きにしては**＋不能、困難等。

1. 実際に話してみ**てからでないと**、相手の考えは分かりません。

2. 値段が高い**からといって**、必ず品質がよいとは限りません。

**2. 疑問詞與後項的呼應**

**釋義：** 「誰、何、どちら、何度」等不一定用來真正提問，也能與其他句型結合，表示不限定、完全否定或感嘆。

**接續：**

- 疑問詞＋**にしても／にしろ／にせよ**：不論哪個選項。

- 誰一人／何一つ＋**として**＋否定：沒有任何例外。

- 何度／どんなに等＋普通形＋**ことか／ことだろう**：強烈感嘆。

1. **どちらにしても**、今日中に返事をする必要があります。

2. この日を迎えるまで、**何度**不安になった**ことか**。

**3. 一＋量詞＋として～ない**

**釋義：** 連一……也沒有。用最小數量與否定呼應，表示完全沒有例外。

**接續：** 一＋量詞＋として＋否定表達。常用「一人、一つ、一度、一日」等。

1. 参加者は一人**として**途中で帰りませんでした。

2. この町で過ごした日々を、一日**として**忘れたことはありません。

**4. ～といった＋名詞**

**釋義：** ……等這類……。前項列舉例子，後面必須接概括類別的名詞。

**接續：** AやB＋といった＋類別名詞。

1. 机や椅子**といった家具**を、まとめて注文しました。

2. 読書や散歩**といった趣味**に使う時間を大切にしています。

**5. ～さえ～ば**

**釋義：** 只要……就……。把前項視為足以讓後項成立的最低條件。

**接續：** 名詞（＋助詞）＋さえ＋ば形。也可用「動詞ます形去掉ます＋さえすれば」。

1. 住所**さえ分かれば**、荷物を送ることができます。

2. 毎日少しずつ練習し**さえすれば**、必ず上達します。

**6. ～をもとにして**

**釋義：** 以……為素材或基礎。把資料、事實或經驗用於加工、整理或創作。

**接續：** 名詞＋をもとにして。修飾名詞時用「～をもとにした＋名詞」。

1. 実際の経験**をもとにして**、この小説を書きました。

2. アンケートの結果**をもとにした**改善案を提出しました。

**7. ～を中心として**

**釋義：** 以……為中心。指出活動的核心、主要對象或範圍的中心。

**接續：** 名詞＋を中心として。也可用「～を中心に」；修飾名詞時可用「～を中心とした＋名詞」。

1. 駅前**を中心として**、新しい店が増えています。

2. この活動は、地域の学生**を中心に**進められています。

**8. たとえ～としても／～にしても／～にしろ／～にせよ**

**釋義：** 即使……也……。「たとえ」提示假設，後項表示結論不因該假設而改變。

**接續：** たとえ＋普通形＋各讓步形式。名詞、な形容詞接「としても」時通常用「だとしても」；接「にしても」等時通常不加「だ」。

1. **たとえ**失敗した**としても**、挑戦した経験は無駄になりません。

2. **たとえ**短い旅行**にせよ**、必要な準備はしておくべきです。

**9. なにも～ことはない**

**釋義：** 不必特地……；沒有必要那麼……。「なにも」與否定呼應，常用於勸告或安慰。

**接續：** なにも＋動詞辭書形＋ことはない。

1. **なにも**今日中に全部終わらせる**ことはありません**。

2. **なにも**一度の失敗で、そんなに落ち込む**ことはない**でしょう。

**10. なんと～ことだろう／～ことか**

**釋義：** 多麼……啊。以「なんと」強調程度，句尾用感嘆表達呼應。

**接續：** なんと＋普通形＋ことだろう／ことか。な形容詞接「な」。

1. **なんと**美しい景色なのだろう、と立ち止まりました。

2. この曲を聴くと、**なんと**懐かしい**ことか**と思います。

> **備註｜區分方法**
>
> - 排列句子時，先找固定組合，例如「さえ＋ば」「たとえ＋としても」「なにも＋ことはない」。
>  
> - 「といった」後面要找類別名詞，不能把它單獨當成完整句尾。
>  
> - 「てからでないと」「ないことには」等提出必要條件，後項通常表示不能、困難或尚無法判斷。
>  
> - 「一＋量詞＋として」要與否定呼應；表示身分的「教師として」則沒有這項限制。
>  
> - 「をもとに」是素材或基礎；「を中心に」是核心、主要對象或活動中心。
>  
> - 第 10 項第一句使用「なんと～のだろう」這個相關感嘆形式；「なんと」也能與「ことだろう／ことか」呼應，不必一律套用同一個句尾。
>

### 類型 35 修飾名詞的形式〔原書第 2 部・第 2 課〕

**本類包含的語法與形式：** ～からの、～への、～としての、～にあたっての、～に基づいた、～に応じた、～に関する、～による、～という、～との等。

**1. 助詞＋の＋名詞**

**釋義：** 把原本修飾動作的地點、方向、來源或對象，改成直接修飾名詞。

**接續：** 名詞＋からの／までの／での／との／への＋名詞。表示對象、方向的「に」通常改為「への」，不說「にの」。

1. 海外**からの荷物**が、今朝届きました。

2. お客様**への説明**は、できるだけ分かりやすくしてください。

**2. 助詞相當語＋の＋名詞**

**釋義：** 在「として、にあたって」等表達後加「の」，直接說明某個名詞的身分、時機或環境。

**接續：** ～としての／～にあたっての／～に際しての／～のもとでの／～を通しての＋名詞等。

1. 教師**としての責任**を、常に意識しています。

2. 新製品の発売**にあたっての準備**を進めています。

**3. 助詞相當語的「た形」＋名詞**

**釋義：** 將「をもとにして、に基づいて、に沿って、に応じて」等改為修飾名詞的形式。這裡的「た」不一定單純表示過去，也可表示成立的關係。

**接續：** ～をもとにした／～に基づいた／～に沿った／～に応じた＋名詞。

1. 現場の状況**に応じた対応**が必要です。

2. 実際のデータ**に基づいた判断**を心がけています。

**4. 助詞相當語的「辭書形」＋名詞**

**釋義：** 以「に関する、による」等形式，把關係直接連接到後面的名詞。

**接續：** ～に関する／～に対する／～による／～における／～にわたる／～に伴う等＋名詞。

1. 新しい制度**に関する質問**を受け付けています。

2. 人口の増加**に伴う問題**について話し合いました。

**5. ～という／～との＋名詞**

**釋義：** 用完整句子的內容說明某個消息、評價、說法或通知。重點是「名詞所包含的內容」。

**接續：** 普通形＋という＋名詞；普通形＋との＋知らせ／連絡／報告等。「との」較正式，並非所有「という」都能直接替換。

1. 来月から料金が変わる**という知らせ**が届きました。

2. 会議は予定どおり行う**との連絡**を受けました。

**6. 內容說明＋其他修飾語＋名詞**

**釋義：** 同一名詞同時受到「という」內容句與形容詞、指示詞等修飾時，形容詞或「あの、その」等通常放在名詞前，讓整體關係清楚。

**接續：** 普通形＋という＋形容詞／指示詞等＋名詞。

1. 地元の高校生が優勝した**といううれしいニュース**を聞きました。

2. この町に昔大きな城があった**というあの話**を覚えていますか。

> **備註｜區分方法**
>
> - 先找被修飾的名詞，再往前判斷哪些內容在說明它。
>  
> - 修飾動作與修飾名詞的形式不同：「法律に基づいて判断する」對應「法律に基づく判断」。
>  
> - 有些表達加「の」，有些改成「た形」或「辭書形」，不能一律加「の」。例如「に関しての説明」雖可見，但教材主要整理「に関する説明」。
>  
> - 「に基づく／に基づいた」「に沿う／に沿った」等有部分重疊，不宜機械地只按過去、現在區分。
>  
> - 「お客様に説明する」改成名詞片語時是「お客様への説明」，不是「お客様にの説明」。
>  
> - 「というニュース」是在說新聞內容；「に関するニュース」則只表示新聞涉及的話題。
>

### 類型 36 否定形式的組合與範圍〔原書第 2 部・第 3 課〕

**本類包含的語法與形式：** ～わけがない、～わけではない、～ようがない、～しかない、～ものではない、～ことはない、～に違いない、～ないではいられない等。

**1. ～わけがない**

**釋義：** 不可能……。強烈否定某件事成立的可能性。

**接續：** 動詞／い形容詞普通形＋わけがない；な形容詞＋な＋わけがない；名詞＋の／である＋わけがない。

1. 一度聞いただけで、全部覚えられる**わけがありません**。

2. 彼がそんな大切な約束を忘れる**わけがありません**。

**2. ～わけではない／～というわけではない**

**釋義：** 並不是……；並不代表……。否定某個推論或概括，不等於全面否定相關事情。

**接續：** 普通形等＋わけではない；普通形＋というわけではない。な形容詞在「わけ」前用「な」。

1. 外食が多いですが、料理ができない**わけではありません**。

2. 日本に長く住めば、自然に何でも話せる**というわけではありません**。

**3. ～というものではない**

**釋義：** 不能簡單地認為……。否定單一條件就足以決定結果的想法。

**接續：** 普通形＋というものではない。名詞、な形容詞現在肯定形式的「だ」可省略。

1. 人数が多ければ、仕事が早く終わる**というものではありません**。

2. 説明は、長ければ丁寧だ**というものではありません**。

**4. ～どころではない**

**釋義：** 哪有餘裕……；根本不是……那種程度。可表示沒有條件做某事，也可否定前項的輕微描述。

**接續：** 動詞辭書形／名詞等＋どころではない。

1. 来客の準備で、昼寝をする**どころではありません**。

2. 外は小雨**どころではありません**。傘も役に立たないほど降っています。

**5. ～ようがない**

**釋義：** 無從……；沒有辦法……。缺少必要資訊、條件或方法，即使想做也無法進行。

**接續：** 動詞ます形去掉ます＋ようがない。

1. 名前も住所も分からないので、探し**ようがありません**。

2. 元のデータが残っていなければ、比較し**ようがありません**。

**6. ～しかない／～よりほかない**

**釋義：** 只能……；別無其他辦法。形式上是否定，整體卻表示前項是唯一可行的選項。

**接續：** 動詞辭書形＋しかない／よりほかない。

1. バスが来ないので、歩いて行く**しかありません**。

2. 詳しい事情が分かるまで、待つ**よりほかありません**。

**7. ～ものではない**

**釋義：** 不應該……。依常識、道理或禮節規勸不要採取某個行動。

**接續：** 動詞辭書形＋ものではない。

1. 人の失敗を、面白がって話す**ものではありません**。

2. 相手の返事を聞かずに、勝手に決める**ものではありません**。

**8. ～ことはない**

**釋義：** 不必……。表示行動沒有必要，與禁止不同。

**接續：** 動詞辭書形＋ことはない。

1. 分からなければ聞けばいいので、無理に推測する**ことはありません**。

2. まだ練習中なのですから、完璧を求める**ことはありません**。

**9. ～てしかたがない／～てたまらない／～てならない**

**釋義：** ……得不得了；不由得……。雖然句尾含「ない」，整體不是否定感受，而是強調感受強烈、難以抑制。

**接續：** 動詞て形／い形容詞くて形／な形容詞で形＋各形式。

1. 合格できるかどうか、不安で**たまりません**。

2. あのときの言葉が気になっ**てなりません**。

**10. ～わけにはいかない／～ないわけにはいかない**

**釋義：**  
① **わけにはいかない**：因責任或立場而不能做。  
② **ないわけにはいかない**：因責任或立場而不能不做。

**接續：** 動詞辭書形＋わけにはいかない；動詞ない形＋わけにはいかない。

1. 秘密の情報なので、詳しく話す**わけにはいきません**。

2. 正式な依頼なので、何も答えない**わけにはいきません**。

**11. ～に違いない／～に相違ない**

**釋義：** 一定……；肯定……。「ない」否定的是「有差異」，整體表示有把握的推斷或確認。

**接續：** 動詞／い形容詞普通形＋各形式；名詞／な形容詞語幹直接接，也可接「である」。

1. こんなに詳しく知っているのだから、実際に見た**に違いありません**。

2. これは、本人が書いた文章**に相違ありません**。

**12. ～にすぎない**

**釋義：** 只不過……。否定超出前項範圍的理解，表示程度、數量或意義有限。

**接續：** 名詞／動詞／い形容詞普通形＋にすぎない；な形容詞可用「である＋にすぎない」。

1. これは、まだ計画の一部**にすぎません**。

2. 私は、見たことをそのまま伝えた**にすぎません**。

**13. ～にほかならない**

**釋義：** 正是……。「不是別的」用來強烈認定本質或原因。

**接續：** 名詞＋にほかならない；原因可用「普通形＋からにほかならない」。

1. 今回の成果は、皆さんの協力の結果**にほかなりません**。

2. 何度も確認するのは、失敗を防ぎたいから**にほかなりません**。

**14. ～に越したことはない**

**釋義：** 最好……；能……自然更好。否定有比前項更理想的選項，整體是正面的建議。

**接續：** 動詞辭書形／ない形、い形容詞＋に越したことはない；名詞／な形容詞＋である＋に越したことはない。

1. 重要な書類は、早めに確認する**に越したことはありません**。

2. 移動する荷物は、軽い**に越したことはありません**。

**15. ～ないではいられない／～ずにはいられない**

**釋義：** 忍不住……。無法維持「不做」的狀態，因此自然會做前項。

**接續：** 動詞ない形＋ではいられない；動詞ない形去掉ない＋ずにはいられない。「する」變為「せずにはいられない」。

1. その知らせを聞いて、喜ば**ないではいられませんでした**。

2. おかしな間違いに気づいて、笑わ**ずにはいられませんでした**。

**16. ～ざるを得ない**

**釋義：** 不得不……。客觀情況使人沒有不做的選擇。

**接續：** 動詞ない形去掉ない＋ざるを得ない。「する」變為「せざるを得ない」。

1. 費用が予想を超えたため、内容を変更せ**ざるを得ませんでした**。

2. 交通機関が止まり、近くのホテルに泊まら**ざるを得ませんでした**。

> **備註｜區分方法**
>
> - 不要看到「ない」就直接判斷整句是否定：  
>     **違いない**＝一定；**ほかならない**＝正是；**しかない**＝只能。
>  
> - **するわけにはいかない**＝不能做；**しないわけにはいかない**＝必須做。
>  
> - **わけがない**否定可能性；**わけではない**否定某個推論或概括。
>  
> - **ものではない**是不應該；**ことはない**是不必；**ようがない**是無從下手。
>  
> - **にすぎない**限制程度；**にほかならない**強調認定；兩者語氣方向不同。
>  
> - **てたまらない**等表示感受很強；**ずにはいられない**等表示忍不住行動。
>  
> - 排列句子時，要把整個固定尾部一起辨認，例如「に＋越したことは＋ない」，不要拆開逐字翻譯。
>

### 類型 37 句首與句尾的正確呼應〔原書第 3 部・第 1 課〕

**本類包含的語法與形式：** ～は～だ、～がある／いる、なぜなら～からだ、～かというと～ない、～のは～ためだ、必ずしも～とは限らない、もしかしたら～かもしれない等。

**1. 名詞主題＋名詞述語**

**釋義：** 用名詞說明某個事物「是什麼」。句首提出原因、目的或問題時，句尾必須回答相應內容，避免主題與述語不匹配。

**接續：** 名詞／名詞化片語＋は／が＋名詞＋だ／である。

1. 私の目標は、地域の人が気軽に集まれる場所を作る**ことです**。

2. 今回の遅延の原因は、部品の不足**です**。

**2. 名詞主題＋形容詞述語**

**釋義：** 說明事物的性質、狀態或評價，回答「怎麼樣」。

**接續：** 名詞＋は／が＋い形容詞／な形容詞述語。

1. この計画で最も重要なのは、参加者同士の協力**です**。

2. 初めて来た人には、駅からの道順が少し**分かりにくいです**。

**3. 名詞主題＋動詞述語**

**釋義：** 說明誰或什麼進行某個動作、發生某種變化。長句中也要確認主體與動作搭配合理。

**接續：** 名詞＋は／が＋動詞。

1. 新しい図書館は、来年四月に**開館します**。

2. この地域の人口は、十年前から少しずつ**増えています**。

**4. 存在主體＋ある／いる**

**釋義：** 表示某處存在某人、某物，或某人擁有時間、問題等。不能把存在主體與述語的角色混淆。

**接續：** 場所／範圍＋には＋名詞＋がある／いる。

1. この建物の中には、自由に使える会議室**があります**。

2. 参加者の中には、日本語を初めて学ぶ人**もいます**。

**5. なぜなら／というのは／なぜかというと～からだ**

**釋義：** 因為……。先提出結論，再用提示理由的表達引出原因，句尾以「からだ／ためだ」等呼應。

**接續：** 結論。なぜなら／というのは／なぜかというと＋普通形＋からだ／ためだ。

1. 私は電車で通うことにしました。**なぜなら**、車より時間が正確だ**からです**。

2. この案には賛成です。**というのは**、費用を抑えながら実施できる**からです**。

**6. ～かというと～ない**

**釋義：** 要說是否……，也不……。先提出可能的理解，再否定或修正它。

**接續：** 普通形＋かというと＋否定或否定性修正。

1. 毎日忙しいかというと、**そうでもありません**。

2. 説明を聞けばすぐに分かるかというと、**必ずしもそうではありません**。

**7. ～のは～からだ／ためだ／名詞だ**

**釋義：** ……的原因是……。以「のは」把前面的事情當作待解釋對象，後項提供原因。

**接續：** 普通形＋のは＋普通形＋からだ／ためだ，或原因名詞＋だ。

1. 予定を変更した**のは**、会場が使えなくなった**ためです**。

2. 彼がこの仕事を選んだ**のは**、学生時代の経験がきっかけ**です**。

**8. ～には～がある／いる／多い／見られる**

**釋義：** 在……之中，存在或可觀察到……。前項設定範圍，後項指出其中的人、事物或傾向。

**接續：** 場所／群體／資料等＋には＋名詞＋が＋存在、數量或觀察表達。

1. この資料**には**、まだ確認が必要な点**があります**。

2. 最近の作品**には**、日常生活を題材にしたもの**が多く見られます**。

**9. ～には～が必要だ／便利だ／かかる**

**釋義：** 要……，需要……；對於……，……很方便。前項提出目的，後項說明條件、工具、所需時間等。

**接續：** 動詞辭書形＋には＋必要條件／工具／時間等。

1. この機械を安全に使う**には**、事前の説明**が必要です**。

2. 市内を移動する**には**、一日乗車券**が便利です**。

**10. 否定副詞與句尾的呼應**

**釋義：** 某些副詞通常要求否定或部分否定的句尾，不能只靠副詞本身完成意思。

**接續與常見搭配：**

- **全く／少しも～ない**：完全不／一點也不。

- **たいして～ない**：不太……。

- **めったに～ない**：很少……。

- **決して～ない**：絕不……。

- **なにも～ことはない**：不必……。

- **必ずしも～とは限らない**：未必……。

1. 私は甘い飲み物を**めったに飲みません**。

2. 経験が長ければ、**必ずしも**判断が正しい**とは限りません**。

**11. 推測副詞與推測句尾**

**釋義：** 「どうやら、恐らく」等提示說話者正在推測，句尾通常也要符合這種判斷方式。

**接續與常見搭配：**

- **どうも／どうやら～ようだ／らしい**。

- **もしかしたら～かもしれない**。

- **恐らく～だろう**。

- **きっと～だろう／に違いない**。

- **まさか～ないだろう／はずがない**等。

1. **どうやら**、入口を間違えた**ようです**。

2. **もしかしたら**、今日は少し遅れる**かもしれません**。

**12. まるで～ようだ／今にも～そうだ**

**釋義：**  
① **まるで～ようだ**：簡直像……，表示比喻。  
② **今にも～そうだ**：眼看就要……，表示即將發生的樣子。

**接續：** まるで＋普通形等＋ようだ；今にも＋動詞ます形去掉ます＋そうだ。

1. 湖の水面は静かで、**まるで鏡のようです**。

2. 空が暗くなって、**今にも雨が降りそうです**。

**13. 變化副詞＋變化表達**

**釋義：** 「ますます、次第に」等表示程度發展，後面應接能顯示變化的述語。

**接續與常見搭配：** 一段と／ますます／次第に／徐々に＋～なる／増える／減る／変わる／～ていく等。

1. 練習を続けるうちに、**次第に**自信が持てるように**なりました**。

2. 夜になるにつれて、風が**ますます強くなってきました**。

**14. いったい／果たして＋疑問表達**

**釋義：** 「いったい」強調疑問或不解；「果たして」表示對結果能否實現抱有疑問。

**接續：** いったい＋疑問詞等＋か／のか；果たして＋～だろうか／～か等。

1. **いったい**、何が起きている**のでしょうか**。

2. この方法で、**果たして**問題を解決できる**でしょうか**。

**15. すでに＋完成或結果狀態**

**釋義：** 已經……。表示在某個基準時間之前，事情已完成，或結果已成立。

**接續：** すでに＋動詞た形／ている形等。

1. 私が着いたとき、説明会は**すでに始まっていました**。

2. 必要な書類は、**すでに提出しました**。

> **備註｜區分方法**
>
> - 長句先縮成「誰／什麼＋怎麼樣」，確認主題與述語的核心關係。
>  
> - 「原因は」後面要回答原因；「目標は」後面要回答目標，不能只因句尾語法正確就忽略內容錯配。
>  
> - 「には」若設定場所或範圍，常接存在、數量；若前接動詞表示目的，常接必要條件、工具或時間。
>  
> - 「なぜなら」與「からだ」等互相呼應；「かというと」則常接否定或修正。
>  
> - 副詞不能單獨決定答案，還要看句尾：尤其區分「必ず」與「必ずしも～ない」。
>  
> - 「まるで」著重比喻；「今にも」著重眼前即將發生的徵兆。
>  
> - 第 2 項第一句也呈現「名詞化主題＋名詞述語」：實際句子可能同時涉及多種結構，分類是辨認工具，不是互斥標籤。
>

### 類型 38 時態、完成與相對時間〔原書第 3 部・第 2 課〕

**本類包含的語法與形式：** 動詞非過去形、動詞た形、～ている、～ていた，以及它們在「とき／場合／際」和名詞修飾句中的用法。

**1. 動詞非過去形表示未來**

**釋義：** 日語沒有獨立的未來式，動作動詞的辭書形或ます形可配合時間詞，表示將來的行動或安排。

**接續：** 未來時間詞＋動詞辭書形／ます形。

1. 来月、新しい部署に**移ります**。

2. 明日は朝九時に家を**出ます**。

**2. 動詞非過去形表示目前狀態或當下行為**

**釋義：** 狀態、能力、感覺等動詞可直接用非過去形描述現在；某些宣告性動詞也用來完成當下的承諾或表態。

**接續：** 状態／能力／感覺等動詞的辭書形或ます形；宣告性動詞的非過去形。

1. 私は車の運転が**できます**。

2. これからも誠実に対応することを**約束します**。

**3. 非過去形表示習慣或不受時間限制的事實**

**釋義：** 描述反覆習慣、一般規律或普遍事實，不限於說話當下。

**接續：** 習慣、規律等內容＋動詞非過去形。

1. 私は毎朝、出勤前に新聞を**読みます**。

2. 地球は太陽の周りを**回ります**。

**4. た形表示過去事件或已完成的變化**

**釋義：** 描述過去發生的事情，也可強調某項變化已經實現。

**接續：** 動詞た形／ました形。

1. 昨日、大学時代の友人に**会いました**。

2. 毎日歩くようになって、以前より体力が**つきました**。

**5. た形不一定表示狀態現在已結束**

**釋義：** 過去形可回顧從過去延續到現在的情況，也常用於剛出現的身體感受或剛發現的事實。不能一律理解為「現在已不如此」。

**接續：** 視動詞與語境使用た形；常與「さっきから、ずっと」等或當下發現的情境搭配。

1. 私は朝からずっとここに**いました**。今も作業を続けています。

2. ああ、おなかが**すいた**。何か食べましょう。

**6. た形表示未來基準點之前的完成**

**釋義：** 在條件句或名詞修飾句中，即使整件事尚未發生，也能用た形表示「到那時已經完成」。

**接續：** 動詞た形＋場合／人／物等，後項依未來情況敘述。

1. 明日、集合時間に**遅れた人**は、自分で会場まで来てください。

2. 来月の説明会に**申し込んだ人**には、開催前日に案内を送ります。

**7. た形修飾形狀或特徵**

**釋義：** 「丸い形をした」等た形可用來描述物體的外形或特徵，不是在報告過去的動作。

**接續：** 形狀、特徵＋をした＋名詞等。

1. 星の形を**したクッキー**を作りました。

2. 赤い屋根を**した家**が、駅の近くにあります。

**8. ～ている表示動作或變化持續**

**釋義：** 表示動作正在進行，或某種變化在一段期間內持續發展。

**接續：** 動詞て形＋いる。

1. 今、会議室で資料を**確認しています**。

2. この町では、外国から来る観光客が**増えています**。

**9. ～ている表示結果狀態或外形**

**釋義：** 某個變化完成後，其結果仍然存在；也可描述物體當前的形狀或樣貌。

**接續：** 常接表示變化、位置或形狀的動詞て形＋いる。

1. 窓が**開いている**ので、少し寒いです。

2. この道は、途中で大きく**曲がっています**。

**10. ～ている表示某個基準時間之前已完成**

**釋義：** 以過去或未來某個時間點為基準，表示到那時事情已完成，結果成立。

**接續：** 時間基準＋動詞ている／ていた／ているだろう等。

1. 私が会場に着いたとき、友人はもう**来ていました**。

2. 来年の今ごろには、新しい建物が**完成している**でしょう。

**11. ～ている表示經驗或紀錄**

**釋義：** 把過去事件當作目前相關的經歷、成績或紀錄提出，而不是只按時間順序敘述過去。

**接續：** 過去時間詞等＋動詞ている。

1. この選手は、五年前にも同じ大会で**優勝しています**。

2. 彼は学生時代に、この町で二年間**暮らしています**。

**12. 從句動作先於主句：た形**

**釋義：** 在「とき、場合、際」等從句或名詞修飾句中，動作若先於主句完成，常用た形。即使主句是未來，也不一定改用非過去形。

**接續：** 動詞た形＋とき／場合／際／名詞等＋主句。

1. 来月、京都に**着いたとき**、まずホテルに荷物を預けます。

2. 商品を間違えて**注文した場合**は、すぐにご連絡ください。

**13. 從句動作後於主句：非過去形**

**釋義：** 從句動作尚未完成，主句動作先發生時，常用非過去形。即使整段敘述是過去，也可能保留辭書形。

**接續：** 動詞辭書形＋とき／際／名詞等＋主句。

1. 昨日、家を**出るとき**、玄関で鍵を確認しました。

2. 明日、友人に**渡す本**を、今日買いました。

**14. 從句與主句同時：非過去形或進行形式**

**釋義：** 兩個動作或狀態同時存在時，從句常用非過去形、ている形；在過去敘述中，也可能使用與主句相應的過去形式。

**接續：** 動詞辭書形／ている形／ていた形＋とき／間／名詞等，依情境選擇。

1. 私が料理を**している間**、子どもは隣の部屋で本を読んでいました。

2. 昨日、雨が**降っていたとき**、私は駅前の店にいました。

> **備註｜區分方法**
>
> - 動詞的非過去形不只表示現在：動作動詞常表示未來或習慣；狀態、能力動詞可表示當前情況。
>  
> - た形不只表示「過去」：也可表示完成、當下感受、外形，或未來基準點之前已完成的事情。
>  
> - 「ている」不只表示「正在」：還可能表示結果狀態、完成、經驗或紀錄。
>  
> - 比較「窓を開けている」與「窓が開いている」：前者可描述開窗中的動作或保持開窗；後者通常描述窗戶已開著的狀態。
>  
> - 複句先找主句的時間基準，再判斷從句是在它之前、之後，還是同時。
>  
> - 「日本へ行くとき」通常著重前往之前或途中；「日本へ行ったとき」通常著重已到日本後的那次經歷，實際仍須結合動詞與情境。
>  
> - 不要因句中出現「明日」就排除所有た形，也不要因主句是過去就把所有從句都改成た形。

### 類型 39 條件、假設與讓步〔原書第 3 部・第 3 課〕

**本類包含的語法與形式：** ～と、～ば、～たら、～なら、～ても、～のに、～ては、～としたら、～となったら、～（よ）うものなら、～ないことには、～を抜きにしては等。

**1. ～と**

**釋義：** 一……就……；如果……就……。常表示自然結果、規律、反覆習慣，或採取動作後發現的事實。

**接續：** 動詞／い形容詞普通形＋と；な形容詞／名詞＋だと。後項通常不直接接命令、邀請、希望或意志。

1. このボタンを押す**と**、画面に説明が表示されます。

2. 窓を開ける**と**、庭に猫がいました。

**2. ～ば**

**釋義：** 如果……就……。提出使後項成立的條件，常用於一般判斷、可能性或所需條件。

**接續：** 動詞ば形；い形容詞去掉い＋ければ；な形容詞／名詞＋なら／であれば。

1. この道をまっすぐ行け**ば**、駅に着きます。

2. 時間があれ**ば**、少し相談に乗ってください。

**3. ～たら**

**釋義：** 如果……；等……之後。既能假設尚未發生的事情，也能表示前項完成後採取行動，或敘述過去的發現。

**接續：** 動詞た形＋ら；い形容詞かったら；な形容詞／名詞＋だったら。

1. 準備ができ**たら**、受付に来てください。

2. 昨日、店に行っ**たら**、臨時休業でした。

**4. ～なら**

**釋義：** 如果是……；既然……。承接對方提出的資訊、打算或當前話題，給予建議、判斷或要求。

**接續：** 動詞／い形容詞普通形＋なら；な形容詞語幹／名詞＋なら。承接已知事實時也常用「～のなら」。

1. 京都へ行く**なら**、このお寺も訪ねてみてください。

2. もう予約したの**なら**、確認メールを見せてください。

**5. ～ても／～でも**

**釋義：** 即使……也……；雖然……仍……。不論前項是假設還是已成立的事實，後項都不因它而改變。

**接續：** 動詞て形＋も；い形容詞くても；な形容詞／名詞＋でも。

1. 明日雨が降っ**ても**、説明会は予定どおり行います。

2. 忙しく**ても**、毎日少しは本を読みたいです。

**6. ～のに**

**釋義：** 明明……卻……；雖然……但是……。前後情況不符合預期，常帶有遺憾、不滿或驚訝。

**接續：** 動詞／い形容詞普通形＋のに；な形容詞／名詞＋なのに。後項通常敘述事實或評價，不直接接邀請、命令或自己的行動決定。

1. 何度も確認した**のに**、書類に間違いが残っていました。

2. 今日は休日な**のに**、朝から仕事の電話がかかってきます。

**7. ～ては／～では**

**釋義：** 如果……就……；照這樣……就……。以前項為條件，指出後面會出現不良結果；也可對已存在的情況作判斷。

**接續：** 動詞て形＋は；い形容詞くては；な形容詞／名詞＋では。

1. そんなに急い**では**、また間違えてしまいます。

2. 毎晩こんなに遅くまで働い**ては**、十分に休めません。

**8. ～としたら／～とすれば／～とすると**

**釋義：** 假如……；假設……。把某個情況當作推論前提，思考行動、結果或問題。

**接續：** 普通形＋各形式。名詞、な形容詞現在肯定形式用「だとしたら／だとすれば／だとすると」。

1. 来年留学する**としたら**、今から何を準備すべきでしょうか。

2. その情報が正しい**とすると**、予定を見直す必要があります。

**9. ～となったら／～となれば／～となると**

**釋義：** 如果真的到了……的情況；既然確定……。強調事情一旦成為現實或明確前提，便產生相應影響、責任或準備需求。

**接續：** 動詞／い形容詞普通形＋各形式；名詞、な形容詞現在肯定形式通常直接接各形式。

1. 海外へ転勤する**となったら**、住む場所も探さなければなりません。

2. その話が事実だ**となれば**、会社として調査する必要があります。

**10. ～（よ）うものなら**

**釋義：** 萬一……就會……。假設某個動作發生，便會帶來強烈或不理想的結果。

**接續：** 動詞意向形＋ものなら。

1. 大事な資料をなくそ**うものなら**、会議が開けなくなってしまいます。

2. 締め切りに一日でも遅れ**ようものなら**、申請は受け付けてもらえません。

**11. ～ないことには**

**釋義：** 不先……就不能……。把前項作為後項成立的必要條件；可談尚未成立的假設，也可說明目前缺少的條件。

**接續：** 動詞ない形＋ことには。後項通常接否定、困難或無法判斷。

1. 実物を見**ないことには**、状態を判断できません。

2. 担当者が戻ら**ないことには**、詳しい返事ができません。

**12. ～を抜きにしては**

**釋義：** 如果沒有……就不能……。強調某個人、因素或觀點不可缺少。

**接續：** 名詞＋を抜きにしては。後項通常接否定或困難。

1. 現場の協力**を抜きにしては**、この改善は実現できません。

2. 利用者の意見**を抜きにしては**、サービスの評価はできません。

**13. ～としても／～にしても／～にしろ／～にせよ**

**釋義：** 即使……也……；就算……仍……。暫且接受前項，後項的判斷或要求依然成立。前項可是假設，也可是承認的事實。

**接續：** 普通形＋各形式。名詞、な形容詞接「としても」時用「だとしても」；接其他形式時通常不加「だ」。

1. 全部完成できない**としても**、できるところまでは進めたいです。

2. 事情がある**にせよ**、無断で休むのはよくありません。

> **備註｜區分方法**
>
> - **と**：自然結果、規律或發現，後項通常不是命令、邀請或自己的打算。
>  
> - **ば**：提出成立條件。前項若是同一主體可控制的動作，後項接意志、請求常受限制；前項是狀態、存在等時，限制較少。
>  
> - **たら**：可表示假設，也可表示「等前項完成後」，後項能接請求、希望或意志。
>  
> - **なら**：承接資訊或話題給建議，不要求前項一定先發生。例如「日本へ行くなら、先に予約する」。
>  
> - **ても**：即便如此，後項仍成立；**のに**：突出事實與預期的落差。
>  
> - **ては**：常指出某條件會帶來不良結果。
>  
> - **としたら**等把事情當假設；**となったら**等更突出事情成真後的實際影響，但兩組用法有重疊。
>  
> - 判斷時先確認前項是「尚未發生的假設」還是「已成立的事實」，再看後項是事實、推測、意志或要求。
>

### 類型 40 動詞選擇、自他動詞與敘述視點〔原書第 3 部・第 4 課〕

**本類包含的語法與形式：** 主動形、被動形、自動詞、他動詞、教える／教わる、貸す／借りる，以及て形連接。

**1. 以行動者為主題敘述動作**

**釋義：** 當說話者或文章主角主動對他人採取行動時，以該人物為主題，可以讓敘述視點保持連貫。

**接續：** 行動者＋は／が＋對象＋を／に＋動詞，助詞依動詞搭配決定。

1. 私は新しく来た社員を、事務所まで案内しました。

2. 私は担当者に、必要な書類を送りました。

**2. 受到他人行為影響時，以被動維持視點**

**釋義：** 前文一直以某人為中心時，後面受到別人行為影響，可用被動繼續以此人為主題。這是敘述選擇，不表示主動句一律錯誤。

**接續：** 受影響者＋は／が＋行動者＋に＋被動形。

1. 私は駅で友人に呼び止められ、しばらく立ち話をしました。

2. 妹は先生に褒められて、うれしそうに帰ってきました。

**3. 從固定立場選擇成對動詞**

**釋義：** 「教える／教わる」「貸す／借りる」「勝つ／負ける」描述同一關係的不同方向。應配合文章主角選擇動詞。

**接續：**

- 教える人＋が＋相手に＋內容を＋教える。

- 教わる人＋が＋相手に／から＋內容を＋教わる。

- 貸す人＋が＋相手に＋物を＋貸す；借りる人＋が＋相手に／から＋物を＋借りる。

1. 私は先輩から仕事の進め方を教わり、翌日から実践しました。

2. 私は友人に借りた本を読み終えたので、今日返すつもりです。

**4. 他動詞：誰かが何かを変える**

**釋義：** 注目するのは行動者による働きかけ。中文可理解為「某人把某物弄成某種狀態」。

**接續：** 行動者＋が／は＋對象＋を＋他動詞。

1. 私は暑かったので、窓を開けました。

2. 係員が入口の前で車を止めました。

**5. 自動詞：何かが動く・変わる**

**釋義：** 注目するのは物事そのもの的移動、變化或狀態，不一定說明誰造成。

**接續：** 變化或動作的主體＋が／は＋自動詞。

1. 強い風で、窓が開きました。

2. 駅の前にタクシーが止まりました。

**6. 他動詞也可表示失誤、責任或慣用表達**

**釋義：** 他動詞不一定表示故意。掉落、遺失等仍可用他動詞描述自己的失誤；有些搭配則需要整體記憶。

**接續：** 人＋が／は＋對象＋を＋他動詞或慣用動詞搭配。

1. 急いでいたので、駅で財布を落としてしまいました。

2. 昨夜、家の鍵をなくしてしまいました。

**7. 自動詞可表示容納能力或動作結果**

**釋義：** 某些自動詞能表示「放得下、打得開」等可能性，也可描述努力後結果是否出現。

**接續：** 對象＋が＋入る／開く／落ちる等。具體意思依情境判斷。

1. この小さなかばんには、ノートパソコンが入りません。

2. 何度洗っても、服についた汚れが落ちませんでした。

**8. て形連接時的主體與因果關係**

**釋義：** 表示連續動作或伴隨動作的「て」，前後通常由同一主體完成；表示原因、理由時，前後主體可以不同。

**接續：** 動詞て形＋後項。需判斷「て」連接的是動作順序、伴隨狀態，還是原因。

1. 私は窓を開けて、部屋の空気を入れ替えました。

2. 電車が遅れて、私は会議に間に合いませんでした。

> **備註｜區分方法**
>
> - 先找文章主角，再選擇「我做了什麼」或「我受到什麼影響」，避免無意識地更換敘述中心。
>  
> - **他動詞**突出行動者的作用；**自動詞**突出事物本身的變化或結果。
>  
> - 「窓を開けた」是某人開窗；「窓が開いた」是窗戶打開。是否有人造成，不是唯一判斷標準。
>  
> - 他動詞不等於故意，例如「財布を落とす」「鍵をなくす」通常不是有意行為。
>  
> - 「汚れを落とそうとしたが、落ちなかった」可在同一句中由行動轉向結果，前後自他動詞不同是合理的。
>  
> - 助詞也不能只用「を＝他動詞」機械判斷；「道を歩く」中的「を」表示經過的路徑。
>  
> - 「て」若表示原因，主體可以不同；若表示同一人的連續動作，要保持主體與動詞搭配一致。
>

### 類型 41 「てくる／ていく」與空間、時間視點〔原書第 3 部・第 5 課〕

**本類包含的語法與形式：** ～てくる、～ていく、～てきた、～ていった及其空間方向、時間持續、變化、出現與消失用法。

**1. 動作完成後，再來／去**

**釋義：** 先做前項，再移動。「てくる」常表示出去做某事後回到基準點；「ていく」常表示先做或帶上某物，再前往別處。

**接續：** 動詞て形＋くる／いく。

1. 近くの店で、飲み物を買っ**てきます**。

2. 友人の家へ行くので、お菓子を買っ**ていきます**。

**2. 以某種方式或狀態移動**

**釋義：** 表示走、跑、攜帶等移動方式。「くる」朝向說話者的基準點，「いく」則離開基準點。

**接續：** 移動方式或伴隨動作的動詞て形＋くる／いく。

1. 子どもが大きな荷物を抱え**てきました**。

2. 彼は駅まで走っ**ていきました**。

**3. ～てきた：從過去持續到現在**

**釋義：** 以前開始的行動或狀態，一直延續到現在或敘述的基準時間。

**接續：** 動詞て形＋きた／きました。

1. 私は十年間、この町で暮らし**てきました**。

2. これまで多くの人に支えられ**てきました**。

**4. ～ていく：從現在繼續到未來**

**釋義：** 從目前或某個基準時間出發，行動、狀態繼續向後發展。

**接續：** 動詞て形＋いく／いきます。

1. これからも毎日、日本語の勉強を続け**ていきます**。

2. 地域の人たちとの関係を、大切にし**ていきたい**です。

**5. ～てくる／～ていく：變化的推進**

**釋義：** 「てくる」把變化看成逐漸發展到現在；「ていく」把變化看成從基準點繼續向未來推進。

**接續：** 變化動詞て形＋くる／いく。常與「なる、増える、減る、変わる」等搭配。

1. 最近、少しずつ暖かくなっ**てきました**。

2. この地域では、今後さらに高齢化が進ん**でいく**でしょう。

**6. ～てくる：出現、產生**

**釋義：** 原本沒有或未被察覺的事物、感受、力量等開始出現，進入說話者的認知範圍。

**接續：** 表示出現、產生等的動詞て形＋くる。

1. しばらく考えていたら、新しいアイデアが浮かん**できました**。

2. 話を聞いているうちに、少し勇気が出**てきました**。

**7. ～ていく：消失、遠離**

**釋義：** 某個事物、聲音或感受逐漸遠離基準點，或走向消失。

**接續：** 表示消失、遠離等的動詞て形＋いく。

1. 電車の音が、少しずつ遠ざかっ**ていきました**。

2. 話し合いを重ねるうちに、互いへの不信感が消え**ていきました**。

**8. ～てくる：狀況開始進入感受**

**釋義：** 某種現象或身體感受開始發生，並被說話者察覺。

**接續：** 動詞て形＋くる；形容詞可先接「なる」，再用「なってくる」。

1. 長く歩いていたら、足が痛くなっ**てきました**。

2. 空が暗くなって、雨が降っ**てきました**。

**9. 同一事件因視點不同而選擇「くる／いく」**

**釋義：** 動作本身相同，若說話者所在位置或心理基準不同，就可能使用不同方向的表達。

**接續：** 移動動詞て形＋くる／いく。先確定說話者或敘述者的基準位置。

1. 私が教室の中で待っていると、学生たちが入っ**てきました**。

2. 私が廊下にいると、学生たちは教室に入っ**ていきました**。

> **備註｜區分方法**
>
> - **くる**朝向基準點；**いく**離開基準點。基準點可以是實際位置，也可以是心理位置或時間。
>  
> - **てきた**常回顧「過去到現在」；**ていく**常展望「現在到未來」。
>  
> - 「買ってくる」常是出去購買再回來；「買っていく」常是買好後帶往目的地。
>  
> - 「走ってくる」中的前項主要說明移動方式，不一定是「先跑完，再來」。
>  
> - **出現、開始**常用「てくる」；**消失、遠離**常用「ていく」。
>  
> - 不能只看句中有「昨日」或「明日」就選形式；「昨日から寒くなってきた」仍是朝目前基準點發展。
>  
> - 文章中若持續從公司、家或某個人物的立場敘述，後面的「くる／いく」也應配合該基準，不要任意切換。
>

### 類型 42 被動、使役與使役被動〔原書第 3 部・第 6 課〕

**本類包含的語法與形式：** 被動形、～によって＋被動形、自發的れる／られる、使役形、使役被動形。

**1. 被動形：受到他人行為影響**

**釋義：** 以受到影響的人為主題，描述他人對其施加的行為。可表示直接作用，也可表示間接受影響。

**接續：**

- 五段動詞：う段改為あ段＋れる；「う」結尾改為「われる」。

- 一段動詞：去掉る＋られる。

- する→される；来る→来られる。

- 受影響者＋は／が＋行動者＋に＋被動形。

1. 私は友人に旅行に誘われました。

2. 電車の中で、知らない人に足を踏まれました。

**2. 被動形：突出事件或對象，省略行動者**

**釋義：** 重點在某事受到什麼處理，而不是誰做的。常用於建築、制度、通知或客觀報導。

**接續：** 事件或對象＋は／が＋被動形。行動者不重要、未知或不必說明時可省略。

1. この建物は、百年以上前に建てられました。

2. 新しい規則は、来月から適用されます。

**3. ～によって＋被動形**

**釋義：** 由……所……。在突出事件或作品的同時，明確指出創作者、發明者或重要施事者，語氣較正式。

**接續：** 對象＋は／が＋施事者＋によって＋被動形。

1. この小説は、若い作家によって書かれました。

2. 新しい治療法は、国際的な研究チームによって開発されました。

**4. 自發表達：～と思われる／～と感じられる等**

**釋義：** 自然覺得……；不由得……。形式與被動相近，但重點是想法、回憶或感受自然產生，不是被某人強迫。

**接續：** 心理活動動詞的「れる／られる」形式。常見「思われる、感じられる、思い出される」。

1. この写真を見ると、学生時代のことが思い出されます。

2. この方法なら、問題を解決できると思われます。

**5. 使役形：要求、安排他人行動**

**釋義：** 讓……做……；使……做……。主語安排或要求另一個人採取行動。

**接續：**

- 五段動詞：う段改為あ段＋せる。

- 一段動詞：去掉る＋させる。

- する→させる；来る→来させる。

- 他動詞常用「指示者＋が＋行動者に＋對象を＋使役形」。

- 自動詞常用「指示者＋が＋行動者を＋使役形」，部分情況也可用「に」。

1. 先生は学生に、作文をもう一度書かせました。

2. 監督は選手たちを、朝早く走らせました。

**6. 使役形：允許他人行動**

**釋義：** 讓……；允許……。與強制不同，主語同意或提供機會，讓對方做想做的事情。

**接續：** 允許者＋は／が＋行動者に／を＋使役形。是否為允許，須依上下文判斷。

1. 両親は私に、好きな進路を選ばせてくれました。

2. 先生は学生たちに、自由に意見を言わせました。

**7. 使役形：引起反應或感情**

**釋義：** 使某人感到……；使某人產生某種反應。原因可以是人，也可以是事件、言語或景象，不一定涉及命令。

**接續：** 原因＋が／は＋感受者を＋使役形。常見「驚かせる、心配させる、楽しませる」等。

1. 突然の知らせが、家族全員を驚かせました。

2. 連絡をしなかったため、両親を心配させてしまいました。

**8. 使役被動形：被迫採取行動**

**釋義：** 被迫……。以實際做事的人為主語，表示不是出於自己的意願，而是受到他人要求或強迫。

**接續：** 動詞使役形去掉る＋られる。常見「書かせられる、食べさせられる、させられる」。部分五段動詞可縮約，例如「書かされる」。

1. 子どものころ、父に毎朝早く起きさせられました。

2. 会議で同じ説明を何度もさせられて、疲れました。

**9. 使役被動形：因某事而不由得產生感受**

**釋義：** 被……弄得……；受到某事影響而不由得……。重點是外在原因引起心理反應，不一定有人強迫。

**接續：** 感受者＋は／が＋原因＋に＋使役被動形。常見「考えさせられる、反省させられる、がっかりさせられる」。

1. その映画を見て、家族の大切さを改めて考えさせられました。

2. 彼の無責任な発言に、がっかりさせられました。

> **備註｜區分方法**
>
> - **被動**：主語受到行為影響，例如「私は先生に褒められた」。
>  
> - **使役**：主語讓別人行動，例如「先生は学生に書かせた」。
>  
> - **使役被動**：主語被迫行動，例如「学生は先生に書かせられた」。
>  
> - 先找「實際做動作的人」，再找「要求或影響他的人」，不要只按中文的「讓、被」選形式。
>  
> - 使役可表示強制，也可表示允許；「選ばせてくれた」通常帶有允許及感謝。
>  
> - 被動不一定是不愉快，例如「招待された」「表彰された」可以是正面事件。
>  
> - 「思われる」等可表示自發判斷；「考えさせられる」則突出外在事件使人思考。
>  
> - 一段動詞的可能形與被動形可能同為「られる」，例如「見られる」，要依主語、助詞與語境判斷。
>  
> - 「によって」適合正式說明重要施事者，不是所有日常被動句都應換成「によって」。
>

### 類型 43 「てあげる／てもらう／てくれる」與受益視點〔原書第 3 部・第 7 課〕

**本類包含的語法與形式：** ～てあげる、～てくれる、～てもらう、～させてもらう、～させてくれる、～てくれない、～てもらえない。

**1. ～てあげる**

**釋義：** 為別人做……。從行動者一方敘述，表示其行為對接受者有幫助。

**接續：** 行動者＋は／が＋接受者に＋動詞て形＋あげる。助詞也可能因原動詞而用「を」等。

1. 私は弟に、宿題の分からないところを説明してあげました。

2. 友人が忙しそうだったので、買い物を手伝ってあげました。

**2. ～てくれる**

**釋義：** 別人為我或我方做……。以行動者為主語，但受益者是說話者或心理上較接近說話者的人。

**接續：** 行動者＋は／が＋我或我方に＋動詞て形＋くれる。受益者常因上下文清楚而省略。

1. 友人が駅まで迎えに来てくれました。

2. 先生が妹の作文を丁寧に読んでくれました。

**3. ～てもらう**

**釋義：** 請別人做……；得到別人……的幫助。從受益者一方敘述，不一定每次都表示事先主動請求。

**接續：** 受益者＋は／が＋行動者に／から＋動詞て形＋もらう。

1. 私は先輩に、報告書を確認してもらいました。

2. 弟は先生に、進路について相談に乗ってもらいました。

**4. 「てくれる」與「てもらう」的主語差異**

**釋義：** 兩者可以描述同一次幫助，但選擇的主語不同。「くれる」以提供幫助的人為主語；「もらう」以得到幫助的人為主語。

**接續：**

- 幫助者＋が＋てくれる。

- 受益者＋が／は＋幫助者に＋てもらう。

1. 田中さんが、私に申請書の書き方を教えてくれました。

2. 私は田中さんに、申請書の書き方を教えてもらいました。

**5. 受益表達與被動表達的評價差異**

**釋義：** 同一行為可因說話者的立場不同，用受益表達呈現幫助，也可用被動呈現受影響或困擾。但被動本身也能是中性或正面，不能一律視為抱怨。

**接續：** 動詞て形＋くれる／もらう；或以受影響者為主語＋被動形。

1. 約束の時間に、友人が電話で起こしてくれました。

2. まだ寝ていたかったのに、朝早く友人に電話で起こされました。

**6. 省略對象時，用受益表達交代關係**

**釋義：** 「某人寫的信、教的歌」不一定能看出是寫給誰、教給誰。加上「てくれた／てもらった」，可讓我方受益的關係更清楚。

**接續：** 幫助者＋が＋動詞て形＋くれた＋名詞；或幫助者＋に＋動詞て形＋もらった＋名詞。

1. 友人が書いてくれた手紙を、今でも大切にしています。

2. 先生に教えてもらった方法で、もう一度やってみます。

**7. ～させてもらう／～させてくれる**

**釋義：** 得到允許或機會，讓我做……。結合使役與受益，表示對方允許、安排或提供某種經驗。

**接續：** 動詞使役形的て形＋もらう／くれる。「聞かせてもらう」等也可表示有機會欣賞、聆聽。

1. 今回は、私が代表として発表させてもらいました。

2. 研究室では、先生が実際の装置を使わせてくれました。

**8. ～てくれない／～てもらえない**

**釋義：**  
① **てくれない**：對方沒有為我方做某事，可帶有期待落空的感受。  
② **てもらえない**：無法取得對方的幫助，重點在受益者無法實現的狀況。

**接續：** 動詞て形＋くれない／もらえない。

1. 何度頼んでも、担当者が返事をしてくれません。

2. 今日は予約がいっぱいで、髪を切ってもらえませんでした。

> **備註｜區分方法**
>
> - **てあげる**：我方或敘述上較接近的一方，為別人做。
>  
> - **てくれる**：別人為我方做，主語是幫助者。
>  
> - **てもらう**：我方得到幫助，主語是受益者。
>  
> - 文章中主語常省略，看到「くれた／もらった」時，要補出「誰做、誰受益」。
>  
> - 「母に教えた方法」是我教給母親的方法；「母に教えてもらった方法」是母親教給我的方法，方向相反。
>  
> - 受益者不只限於「我」，也可包括家人、朋友或文章中作為敘述中心的人。
>  
> - 「てあげる」帶有提供恩惠的意味，直接對長輩或服務對象使用，有時顯得居高臨下；一般服務說明用普通動詞即可。
>  
> - 「てくれる」與「てもらう」都帶有受益立場；被動則不保證有受益意味，要看上下文。
>  
> - 「させてもらう」不只是禮貌包裝，也應理解為得到允許、協助或機會；不是所有自己的動作都需要加上這個形式。
