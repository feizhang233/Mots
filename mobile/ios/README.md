# Mots for iPhone

原生 SwiftUI App，最低 iOS 26，使用系統 Liquid Glass 與 SF Symbols。無 WebView、無 Material 3、無第三方 Swift 套件。App 保留內建詞庫作離線起點；新同步版本會從 VPS 驗證並下載公開詞庫更新。私人詞典內容與學習進度存於裝置 Application Support，配對後雙向同步。

## 開啟與安裝

在專案根目錄執行 `make ios-assets`，再開啟 `mobile/ios/Mots.xcodeproj`。選擇 Mots scheme、自己的 Apple 開發簽名 Team，以及連接的 iPhone 或已安裝的模擬器，執行 Run。開發者帳戶和裝置授權需由使用者在 Xcode 設定。預設 Bundle ID 為 `com.feizhang.mots`，如帳戶已佔用，改為自己的唯一識別碼。

重新生成工程會保留在 Xcode 設定的 Team、Bundle ID、版本與構建號。資源來源仍位於 `Mots/Resources/`，但只把 `catalog.json` 和 `audio/` 分別複製至 App 的標準資源位置；不在 iOS App 根部建立名為 `Resources` 的資料夾，避免被簽名工具誤判為其他 Bundle 格式。若使用早期構建，先在 Xcode 執行 Product → Clean Build Folder，再 Run。

`make ios-build` 可產生不簽名的 iOS Release 構建，用於編譯檢查。它不能直接安裝至手機。分發需在 Xcode 完成簽名及 Archive；此專案尚未提交 TestFlight 或 App Store。

本次使用 Xcode 27.0 / iOS 27 SDK。Duo 的完整邊緣與垂直控制列行為以最新版 Xcode SDK 為準；Apple 建議使用 Xcode 27.1 驗證所有姿態。不要以 Catalyst 或網頁尺寸檢查代替 Duo 裝置／模擬器測試。

## 布局與操作

- 分類只剩一個有內容的子類時，目錄直接選取該主題，不顯示重複的二級選單；空白分類及子類不顯示。iPhone 的緊湊版型中，語法列表只顯示各編號含義的首句，保留「；」或「／」連接的不同意思；例句移到詳情，詳情與熟悉度按鈕同列。完整解釋與例句仍保留於詳情、卡片、搜尋與備份。較寬的 iPad 版型保留完整語法列表。
- 一般 iPhone／Duo 外螢幕：單欄學習畫面，左上「分類目錄」開啟目錄，選擇後回到內容。
- Duo 展開／較寬視窗：由 `NavigationSplitView` 和系統尺寸類別決定分欄、覆蓋或收合。沒有機型判斷、固定螢幕座標或以裝置方向推測內外螢幕。
- 折疊／調整視窗不重建 `StudyStore`，保留選中辭典、單字、答案顯示、搜尋和複習隊列。進度和學習位置另外持久化至本機。
- 導航、選單及按鈕使用系統 Liquid Glass；內容卡片保留不透明底色。設定 → 學習偏好 → 外觀可選「跟隨系統」「一般模式」或「深色模式」，立即套用全 App 並儲存在本機與備份。Dynamic Type、減少動態及減少透明度設定受到支援。
- 查詞包含全部熟悉程度的單字；主題學習的篩選選單與設定 → 學習偏好可分別開關「隱藏有印象」與「隱藏已掌握」，預設關閉，選擇會保存並包含在備份。隱藏只影響主題學習，不會清除進度，也不影響查詞、隨機複習或卡片記憶。隨機複習每輪最多 20 詞，優先未熟悉／有印象，可翻頁瀏覽，最後一詞點「完成本輪」。
- 卡片記憶保留每本書的原輪次、目前卡片、已作答項目、答案顯示、章節選擇及完成摘要。重新啟動或切回此模式直接續讀；返回章節選擇會暫停，可「繼續上次」，只有「開始新一輪」會重新選詞。這些閱讀位置保存在本機，不參與配對同步或跨裝置備份轉移。
- 卡片記憶的新書籍預設不選章節，明確選擇後按書籍保存；每輪包含所選章節的全部到期詞，不設學習詞數上限。每次開始新一輪會隨機排列到期詞，繼續上次、作答、切換書籍與重新開啟均保留捕獲的順序。首次立即背誦，其餘四次依次間隔 1、2、4、7 天，共完成 5 次成功回想後轉為已掌握；忘記則重新計算，1 天後再複習。逾期只按實際成功次數推進一輪，下次間隔從當次作答時計算。舊版尚未掌握的第 5–8 次進度保留原到期日並等待最後一次實際回想，舊版已掌握狀態繼續保留。
- 目錄的一級／二級單元使用各自的詞條範圍；列表不再顯示辭典標題、語言及掌握統計區。
- 列表標題與篩選按鈕在同一水平列置中對齊，移除原本的卡片／列表分段切換；右上學習方式選單仍可選擇卡片或列表。
- 卡片頂部只以一行進度條與「目前詞序/本組詞數」呈現位置；不顯示搜尋、篩選和列表控制區。右上學習方式選單可切回列表。
- 卡片移除回想提示，可左右滑動進行原生翻頁；底部依序為上一詞、綠色已掌握、黃色有印象、紅色不熟悉、下一詞。三色按鈕不顯示漢字，選擇後自動前往下一詞，保留無障礙標籤。完成翻頁才儲存位置，取消手勢不改進度；按鈕翻頁與評分直接切換，避免與手勢翻頁重疊。卡片畫面持續觀察學習位置及詞組，避免手勢期間的更新中斷後只更新底部進度、卡片仍停在原處。翻頁期間的新選擇保留優先權，逾時或離開畫面會釋放翻頁狀態；每一張新卡片答案預設隱藏，長內容可垂直捲動。揭曉後顯示釋義、接續與最多兩個不同例句。設定的「學習偏好」提供預設開啟的「卡片顯示例句翻譯」，只顯示目前釋義語言已有的翻譯；關閉後保留原文。此偏好儲存在本機及備份，不參與資料同步。只有語法卡片提供「查看詳情」，可讀完整例句及用法說明。詞彙卡片及列表不設詳情入口。
- 頂部書名、分類目錄及設定可切換獨立詞彙／語法書籍；語法列表採詞條／釋義與例句／熟悉度的雙排布局，另設詳情入口。列表與詳情的例句維持原文。
- 列表中的搜尋只影響列表，切到卡片後暫停、切回後恢復。詞彙列表每列只顯示單字、釋義和右側紅／黃／綠的純色熟悉程度按鈕，不顯示例句與獨立發音符號。篩選選單及設定的「學習偏好」提供預設關閉的「先隱藏翻譯」：開啟後主題學習列表先只顯示單字，點單字／釋義區會顯示目前單字的翻譯並發音，點其他單字會重新隱藏上一個翻譯；再點目前單字可停止播放，翻譯繼續顯示。查詞仍顯示所有釋義。隱藏的翻譯保留排版空間，但不顯示或向輔助使用功能讀出。熟悉程度按鈕獨立操作，不觸發發音或揭曉。重點已選等級可清除；列表標記不自動翻頁，隱藏已掌握時仍即時移除該列。
- 「先隱藏翻譯」偏好會儲存在本機並包含於備份；已揭曉的單字只保留於本次列表瀏覽，換頁、切換範圍／書籍／學習方式／版型、變更此偏好或離開列表後重新隱藏。這些顯示設定不參與資料同步；語法列表維持原有的釋義顯示方式。

應用圖標由 `scripts/create-icon.swift` 生成為不透明的 1024×1024 RGB PNG，透過 `AppIcon.appiconset` 打包；圓角由 iOS 系統處理。

最新列表精簡、右側純色熟悉程度與點擊發音的模擬器驗證見 [`../../qa/ios/compact-list/verification.md`](../../qa/ios/compact-list/verification.md)。卡片翻頁與圖標的早期驗證保留在 [`../../qa/ios/paging-list-update/verification.md`](../../qa/ios/paging-list-update/verification.md)。

N2 紅寶書自 build 11 起內置，書籍選單可切換至「日本語 N2 紅寶書」。列表和卡片以右側括號顯示讀音，例句保留已對齊的括號讀音；播放優先使用指定讀音，例如空讀作から。沿用既有書籍／詞條 ID，熟悉度與記憶排程可從原有配對恢復。

## 內容與備份

`make ios-assets` 執行 `scripts/export-content.cjs`，從現有 Web 內容載入器產生 `Mots/Resources/catalog.json` 和單字讀音。語法沒有預錄音，使用裝置對應語言的語音。詞彙書包含法語 3,846 詞、德語 12 詞、日語 414 詞、N2 紅寶書 3,136 詞（使用指定假名的裝置語音）；法語／德語語法入門書各 6 項，日語普通語法 141 項、主題語法 229 項，合計 7,790 個項目。日語語法按已匯入來源分課，普通／主題書保留獨立內容與進度；法語／德語主題語法書仍待來源。`Resources/audio/` 是可重新生成的副本，不重複納入 Git；來源是專案 `database/runtime/` 的共用詞庫和音訊。

根目錄 `make build` 另外產生 `database/catalog.json` 和 `database/content-version.json`，將 App 內置詞庫與 VPS 公開詞庫綁定為同一內容版本。`make check`／`make sync-vps` 會拒絕詞庫或來源清單不一致的版本。這仍是發布時的一致性檢查。支援完整資料同步的新 App 另外會讀取 VPS 的版本清單，驗證詞庫 SHA-256 後下載並快取；這套客戶端更新需要先安裝一次，之後公開詞庫更新不必再重裝。個人詞典修訂使用獨立配對通道，公開更新不會覆蓋私人修改或學習進度。

設定的「辭典匯入與生詞」提供辭典 JSON 匯入、欄位說明、可捲動的範例預覽與「下載範例模板」；主畫面不設匯入入口。模板沿用目前書籍的語言、詞彙／一般語法／主題語法類型及首個詞條，空白書籍則提供可直接匯入的占位範例。預覽與下載使用同一產生器；最多 2 MB、5,000 個詞條。匯入後加入獨立書籍並切換至該辭典。

設定也可匯入 Web v1–v3 備份、匯出相容 v3 備份，以及按全部／一級／二級單元匯出生詞 CSV。相同辭典 ID／詞條 ID 使用匯入進度，其他內容保留；先驗證整份輸入再合併。CSV 排除已掌握詞，與畫面搜尋和頁碼無關。

App 與線上網站的設定均提供「資料同步」：一端建立配對碼，另一端輸入一次。前景連線時自動交換熟悉程度、卡片記憶排程與單字刪除／還原狀態，離線修改在恢復連線後合併。首次配對合併既有進度；沒有修訂資訊的舊記錄衝突採較高熟悉程度，之後清除／降低也會同步。配對碼只存 Keychain，不包含於備份。斷開配對保留本機進度；自訂詞典、擴充詞條和既有詞條的私人修改也會同步；偏好、章節選擇及閱讀位置仍只留在本機。相同辭典／詞條 ID 才會合併，配對群組以外不可讀寫私人內容。存檔錯誤會保留記憶體內工作並顯示錯誤，請先匯出備份。卸載 App 可能清除本機進度。

資料同步、正式網站與真機安裝驗證見 [`../../qa/progress-sync/verification.md`](../../qa/progress-sync/verification.md)。

iOS 支援 Unicode 詞條 ID。若遠端卡片排程的辭典或詞條 ID 與本機另一個 ID 只有 Unicode 編碼形式不同（例如預組字母 `é` 與 `e` 加組合重音），目前的本機存檔無法同時區分兩者。遇到這種衝突時，App 會保留原有排程、顯示原因，並拒絕套用該批排程。

## 維護

| 檔案                            | 責任                                                       |
| ------------------------------- | ---------------------------------------------------------- |
| `Mots/App/`                     | App 入口、自適應導覽與學習方式的顯示名稱                   |
| `Mots/Features/Study/`          | 學習畫面、卡片翻頁、原生列表、側滑刪除與撤銷               |
| `Mots/Features/Settings/`       | 折疊設定、已刪除單字還原、同步與檔案轉移介面               |
| `Mots/Domain/Models.swift`      | 詞庫模型與匯入驗證                                         |
| `Mots/Data/StudyStore.swift`    | 查詞、熟悉度、可見詞條、穩定複習隊列、原子存檔與相容備份   |
| `Mots/Sync/`                    | 兩種修訂記錄、共用識別規則、Keychain 配對與 HTTPS 同步調度 |
| `Mots/Shared/`                  | 原生語義色彩、閱讀卡片與共用熟悉度／發音控制               |
| `Mots/Audio/SpeechPlayer.swift` | 離線讀音、裝置語音及單一播放生命週期                       |
| `scripts/sources.json`          | Xcode 與原生測試共用的來源清單；model 範圍不包含 SwiftUI   |
| `scripts/generate-project.py`   | 依來源目錄產生 Xcode 分組，保留 Team、Bundle ID 與版本設定 |
| `scripts/test.sh` / `Tests/`    | Store、雙通道同步、刪除還原與工程結構測試                  |

`make ios-check` 驗證內容與原生資料邏輯。`make ios-preview-build` 建立同源的 Mac Catalyst 預覽以檢查原生互動，不代表 iPhone／Duo 驗證。完整本次證據和限制見 [`../../qa/ios/verification.md`](../../qa/ios/verification.md)。
